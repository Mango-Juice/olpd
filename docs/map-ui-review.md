# 고정 화면과 장면 가독성 검토

이전 가로 스크롤 맵은 폐기했다. [그때의 검토](history/map-ui-review-before-quiet.md)는 역사 기록이며 현재 기준이 아니다. 현재 기획은 [공통 플레이 계약](stage-design/00-play-contract.md)을 따른다.

## 변경

- 복합 장치가 늘어날 때 캔버스를 늘리던 방식을 없앴다. 현재 후속 54장면은 각 2~4개 요소만 배치하고 960×500 고정 구도를 유지한다.
- 장면마다 `scene.floors`로 바닥·틈·높은 선반을 지정한다. x/y는 실제 물체·캐릭터 위치를 그리는 데 사용한다. 방 전체를 물건 카드 행으로 재배치하지 않는다.
- 원본 1장의 석조 배경·바닥·모루를 공유하고 목판 상자, 문, 사다리, 벽고리, 의자, 관측창, 갑옷 부품의 형태를 보강했다. 사다리는 실제 위층 바닥에 닿고, 들고 있는 물건은 주체와 함께 움직인다.
- 선택 후 상세 데이터 패널, 물체 카드 목록, 숫자 성질·무게·범위·슬롯 표시를 없앴다. 장면의 짧은 이름과 입장 목적 한 문장만 기본 안내로 사용한다. 이름을 선택해도 설명 단계를 열지 않는다.
- 모바일은 지도 전체 구도를 유지하면서 이름표만 역축척한다. 바닥과 오브젝트 위치를 바꾸지 않고 이름표 경계·충돌을 따로 검사한다.
- 입력창은 모든 장이 같은 `PlayCommandComposer`와 `usePlayCommand`를 쓴다. Enter 후 별도 확인·출발 단계가 없다.

## 검증

`npm run test:campaign:scenes`가 후속 54개 초기 장면과 9개 장의 모바일 너비를 검사한다. 요소 이름표·좌표 경계, 가로 넘침, 내부 패널 제거와 런타임 오류를 확인하며 AI는 호출하지 않는다. 실제 캡처를 보고 짧아 보이던 양끝 바닥, 상자의 재질, 위층과 끊긴 사다리, 의자와 다리의 구분, 분기 통로, 문지기 부품의 소속을 보완했다.

당시 캡처는 `artifacts/quiet-scenes/`, 입력 검사는 `artifacts/quiet-command/`에 보관했다. 현재 명령은 각각 `artifacts/campaign-scenes/`, `artifacts/shared-campaign/`에 새 결과를 남긴다. 초기 장면 전수 검사와 대표 상태 검증이며 모든 가능한 중간 화면이나 사람의 직관성을 전수 검증했다는 뜻은 아니다.
