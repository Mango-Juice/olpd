# 던전 Canvas 아트 디렉션

## 장면 기준

Canvas 장면은 960×500 논리 좌표를 기준으로 하며, 브라우저에서는 DPR 2를 상한으로 선명하게 확대한다. 화면 비율은 1.92:1이다. 배경·장애물·이펙트는 Canvas 도형과 그라디언트로 그리고, 주인공은 투명 PNG 스프라이트 시트를 source crop으로 재생한다.

- 후경: 둥근 보랏빛 벽돌, 세 겹 석조 아치, 심연 실루엣과 넓은 달빛 기둥
- 중경: 덩굴과 잎, 횃불의 주황색 광원, 얇은 청록 안개, 출구 문
- 플레이 면: 모서리가 둥근 보랏빛 석재 바닥, 차가운 금속 가시, 목재 다리, 민트색 샛길, 작은 발광 버섯
- 캐릭터: 크림색 몸과 작고 부드러운 남색 눈, 복숭아색 귀, 민트 후드와 금빛 달 장식이 있는 오리지널 마스코트 ‘모루’. 투명 시트의 자세별 실제 경계와 바닥 기준점을 따로 지정해 약 100px 높이로 축소하며, 셀 경계의 다른 포즈가 섞이지 않게 한다. `detour`는 안정적인 걷기 포즈를 곡선 경로에서 재사용한다.

위험물은 색만으로 구분하지 않는다. 구덩이는 바닥이 완전히 끊긴 실루엣, 끊어진 다리는 늘어진 밧줄과 어긋난 판자, 바닥 가시는 위쪽 삼각 실루엣, 천장 가시는 낮은 석재 덩어리와 아래쪽 삼각 실루엣을 사용한다. 샛길은 화살표만 띄우지 않고, 위험물 전에 갈라지는 경사로·벽에 붙은 상단 석재 회랑·위험물 뒤 합류 경사로를 하나의 연속된 물리 통로로 그린다. 직진 바닥과 상단 회랑은 약 150px 떨어지며, 두 방향 표지와 석재 이음새가 하나의 분기와 하나의 합류를 명확히 보조한다. 구덩이까지 내려가는 다리 지지대는 사용하지 않는다.

## 모션 기준

캐릭터는 `idle`, `walk`, `jump`, `duck`, `detour`, `death`, `revive`, `joy`의 여덟 자세를 가진다. 점프 안에는 웅크린 도약 준비, 공중 호, 눌리는 착지가 연속으로 들어간다. 우회는 점프 포물선을 사용하지 않는다. `430,402 → 455,320 → 490,252` 분기 경사, `490,252 → 660,252` 상단 회랑, `660,252 → 695,320 → 720,402` 합류 경사를 걷는다. 통로와 발 좌표는 같은 `detourPathPoint`를 사용하고, 상단 회랑에서는 캐릭터·그림자·먼지가 함께 72%로 작아진다. 상단 회랑은 위험물 실루엣과 겹치지 않으므로 x-ray나 반투명 위험물은 사용하지 않는다. 접근 종료와 행동 시작은 `430`, 행동 종료와 퇴장은 `720`으로 이어져 순간이동이 없다. 사망은 쓰러진 몸이 남거나 입구까지 걸어 돌아가지 않는다. 위험 지점에서 짧게 눌리고 별·연기와 함께 디졸브한 뒤, 다음 장면에서 `START_X`의 달빛 소환 이펙트로 나타난다.

일반 이벤트는 4.2초, 이미 본 이벤트는 정확히 3배 빠른 1.4초 동안 재생한다. 게임 코어가 생사와 점수를 먼저 확정하고 Canvas는 그 결과를 표현한다. 이벤트마다 재생 종료를 한 번만 알리며, 이벤트가 없을 때는 종료 신호를 보내지 않는다. 재시작 중에는 `onSceneModeChange("entrance")`, 새 행동이 실제로 시작될 때는 `onSceneModeChange("action")`을 한 번 전달해 HTML 설명과 장면을 맞춘다.

`prefers-reduced-motion` 값은 상위 UI가 `reducedMotion` prop으로 전달한다. 이 설정에서는 먼지 수, 식물 흔들림, 불꽃 변화를 줄이고 부활 시간을 단축한다. 명시적 일시정지 또는 숨겨진 탭에서는 애니메이션 시간을 누적하지 않는다.

렌더러는 표시 중인 프레임률을 1초 단위로 관찰한다. 45fps 미만이 2초 이어지면 이동과 판정 재생 시간은 유지하면서 먼지, 식물 흔들림, 불꽃 변화만 감소시킨다.

## 출처와 변경 규칙

배경과 이펙트는 `src/render/scene.ts`의 Canvas 경로, 그라디언트, 도형으로 제작했다. `public/art/moru-sprite-sheet-v3.png`는 2026-09-22 OpenAI ImageGen으로 이 프로젝트를 위해 생성한 투명 PNG다. 프롬프트는 기존 캐릭터를 복제하지 않고 크림색의 둥근 동물형 탐험가, 민트 후드, 금빛 달 장식, 완전한 팔다리와 넓은 포즈 간격, 작은 콩 모양 눈과 편안한 시선을 지정했다. 배포본은 1774×887 RGBA이며 브라우저 Canvas 픽셀 검사에서 시트 모서리의 알파값이 0임을 확인했다. 포즈별 연결 요소의 실제 경계와 기준점을 측정해 source crop하며, 단순 격자 분할은 사용하지 않는다. 서드파티 게임 에셋은 사용하지 않는다.

새 위험물을 추가할 때는 관찰 데이터와 장면의 정보를 일치시킨다. 실루엣만 본 상태에서도 기존 위험물과 구분되어야 하고, 캐릭터보다 높은 대비를 쓰지 않으며, 이동 가능한 경로를 가려서는 안 된다.

## 소리

`src/game/audio.ts`의 Web Audio 합성으로 발걸음, 도약, 착지, 작성, 삭제, 사망, 부활, 성공을 구분한다. 첫 사용자 입력 이후 AudioContext를 열며 음소거는 마스터 gain에도 반영한다. 렌더러의 진행률 큐를 사용해 장면과 동기화하고 3배속에서는 발소리 수를 줄인다. 배경 음악은 사용자 제스처 이후 실제 재생 중에만 스테이지 흐름에 맞춰 더해진다. 자세한 재생·전환 규칙은 [오디오 디자인](./audio-design.md)을 따른다.
