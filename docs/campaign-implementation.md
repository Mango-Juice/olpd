# 캠페인 구현 — 한 화면의 작은 여정

현재 기준은 [스테이지 설계 v2](stage-design/README.md)다. 이전 80장면 구현 보고서는 [역사 기록](history/campaign-implementation-before-quiet.md)으로 옮겼다. 아래 변경은 로컬 구현이며 배포하지 않았다.

## 현재 동작

- 1장 12장면과 2~10장 각 6장면, 총 66장면이다. 후속 54장면의 필수 요소는 목표·위험·조작물을 합해 각각 2~4개다.
- 맵은 960×500의 고정 구도다. 화면에 맞춰 전체를 축소하고 모바일 이름표만 읽기 좋게 보정한다. 가로 스크롤·줌·카메라 추적·물체 목록·상세 성질 패널은 없다.
- 입장할 때 달성할 목적을 한 문장으로 알린다. 해결 순서와 내부 수치는 노출하지 않는다. 손잡이·발판·문·물길의 실제 위치와 상태 변화를 그린다.
- 프롤로그·1장·후속 장은 모두 입력 후 Enter 한 번으로 해석·저장·실행한다. 별도 확인·메모 확정·출발 단계가 없다. `PlayCommandComposer`와 `usePlayCommand`가 Enter, 한글 조합, Shift+Enter, 요청 중복, 취소, 늦은 응답, 오류를 공통으로 처리하고 각 실행기는 저장·행동 어댑터를 제공한다.
- 후속 장은 매 장면에서 무료로 한 줄을 고치고 재시도한다. 이미 완료한 장면을 다시 통과하지 않는다. 장면별 원문은 `sceneNotes`에 보존한다. 기존 1장 본편의 기억 규칙은 유지한다.
- 전 장 클리어에 따른 순차 해금, 동화책 여정 지도, 기존 음악·이야기·편지 결말을 유지한다.

## 코드와 저장 경계

`src/campaign/quiet/`가 새 장면 정의다. 현재 registry는 이 정의만 사용한다. 옛 `stages/` 파일은 이전 물리 규칙의 회귀 fixture로 남아 있으며 현재 플레이 경로에 연결하지 않는다.

새 장면 ID는 `02-v2-1` 형식이고 런의 `contentRevision`은 `quiet-v1`이다. 저장 문서를 읽기 전에 기존 2장 이후 활성·완료 원본을 같은 IndexedDB 트랜잭션의 복구 기록으로 보존한다. 이전 완료와 해금·시간은 유지하고 새 장면의 완료로 바꾸지 않는다. 여정 지도에서 개편 전 자료를 내려받을 수 있다. QA도 별도 새 저장 키를 사용하며 옛 QA 키는 지우지 않는다.

각 새 장면은 실제 위치·소유·관찰·장치 상태로 완료를 판정한다. 자연어 문장이나 정답 문자열을 실행기에서 대조하지 않는다. 이동·탑승·도구 사용의 일상적 표현은 같은 물리 의미로 처리하되, 위험 통과·미관찰 정보·동료 역할을 임의로 해결하지 않는다.

## AI와 검증 범위

프롤로그·1장은 Jev, 후속 장은 기존 `deepseek-flash`를 사용한다. 요청당 1회, 기본 non-thinking, 자동 재시도·모델 대체는 없다. 새 장면 전용 짧은 해석 계약을 사용하고 불필요한 무게·용량·도달 거리 숫자는 모델 입력에서도 생략한다. AI는 행동 프로그램만 반환하며 승패를 결정하지 않는다.

2026-09-22 실제 API 검사: 새 54장면 대표 한국어 의도를 각각 해석하고 실제 `StageRun`으로 실행했다. 첫 검사 38/54, 실패 표현의 실행기·조건 어휘·해석 누락을 보완하고 해당 사례만 재검사해 각 장면의 최종 관측 결과는 54/54다. 총 72회 호출, 입력 127,902토큰·출력 6,999토큰. 측정 지연 중앙값 약 0.99초, 95백분위 약 1.31초, 최대 1.50초였다. 호출 환경의 관측치이며 서비스 지연 보장은 아니다. 마지막 프롬프트를 적용해 54개 전체를 다시 호출한 결과는 아니며, 수정된 실행기로 반환 AST의 회귀 검사를 수행했다.

- 단위·통합 검사: 58개 파일 638개 테스트, 타입 검사·프로덕션 빌드 통과. 후속 9개 장 전체에서 매 실행 경계를 직렬화·복원한 뒤 6장면 완료와 원문 보존을 확인했다. 빌드에는 기존 500kB 초과 JS 청크 경고가 남는다.
- 브라우저 맵: `npm run test:campaign:scenes` — 54개 초기 장면과 9개 장 모바일에서 고정 폭·가로 넘침·내부 패널 제거, 오류 없음. API 호출 없음.
- 공용 입력: `npx tsx scripts/browser-quiet-command.ts`, `npm run test:onboarding:legacy` — Enter 즉시 실행, IME, 취소, 늦은 응답, 오류 입력 보존, 빠른 중복 제출, 저장·재접속·인계. 해석 응답은 fixture이며 게임 실행과 저장은 실제 코드다.
- 브라우저 저장 복구: `npx tsx scripts/browser-quiet-recovery.ts` — 실제 IndexedDB의 개편 전 활성 원본, 이전 완료 시간·해금 보존, 새 장면 저장과 재접속 확인. 여정 지도의 시작·이어 하기·잠금도 별도 브라우저 검사 통과.
- 실제 AI 재현: `npx tsx --env-file=.env.local scripts/evaluate-quiet-live.ts --ids=02-v2-1` 또는 명시적 `--all`. 유료 호출이며 자동 재시도하지 않는다.

화면과 대표 행동에 대한 검증이다. 자동 통과를 사람의 재미나 난이도 해결의 증명으로 표현하지 않는다. 이전에 중단한 독립 블라인드 플레이테스트는 재개하지 않았다. 보고서·캡처는 Git 제외 경로 `artifacts/quiet-*`에 둔다.
