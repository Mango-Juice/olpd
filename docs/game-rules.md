# 메모 수칙 — 공통 실행 규칙

2026-09-23 사용자 확인. 프롤로그·1장에서 확립한 메모의 의미를 모든 장에 적용한다. 메모 선택·우선순위·반복 실행에 대해서는 이 문서가 기준이며, 과거 구현·검증 기록이 다른 규칙을 설명하더라도 현재 설계로 인용하지 않는다.

## 메모는 소모되지 않는다

메모는 한 번 처리하고 지우는 작업 목록이 아니라 용사가 계속 기억하는 수칙이다. 행동을 결정할 때마다 현재 상황에 맞는 수칙을 화면 위에서 아래로 검사하고, 처음 맞는 하나를 실행한다. 다음 판단에서도 맨 위부터 다시 검사한다. 한 번 실행했거나 이전에 성공했다는 이유로 후보에서 제외하지 않는다.

- 조건 없는 수칙은 적용 범위와 대상이 맞으면 항상 후보다.
- 조건이 맞지 않는 수칙은 아래 수칙으로 넘어간다. 조건을 확인할 수 없는 경우에는 확인이 필요하다고 알리며 임의로 참·거짓을 정하지 않는다.
- 위쪽 수칙이 계속 맞으면 아래 수칙은 실행되지 않는다. 행동이 막혔다고 아래 수칙으로 자동 우회하지 않는다.
- 맞는 수칙이 하나도 없으면 이동하지 않는다. 시스템이 전진 수칙을 만들어 주지 않으며, 이 정지 자체는 사망이 아니다.
- 한 동작의 성공, 한 수칙의 실행 종료, 스테이지 클리어는 서로 다르다. 실행 종료가 수칙 소모를 뜻하지 않는다.
- 새 판단은 기록된 한 행동의 재생이 끝나는 경계에서 한다. 출구까지 걷는 명령도 한 걸음의 판정·재생이 끝나면 상위 조건을 다시 확인한다. 목적지에 도착할 때까지 해당 수칙이 우선순위를 독점하지 않는다. 화면 프레임마다 AI를 호출하거나 재생 중간의 미확정 위치로 수칙을 고르지 않는다.

## 우선순위의 의미

| 위쪽 수칙 | 아래쪽 수칙 | 선택 |
| --- | --- | --- |
| 상자가 보이면 점프해 | 앞으로 전진해 | 상자가 보이면 점프, 그렇지 않으면 전진 |
| 앞으로 전진해 | 상자가 보이면 점프해 | 전진이 항상 먼저 맞으므로 전진. 순서를 바꾸는 것이 플레이어의 판단 |
| 문이 닫혀 있으면 열어 | 앞으로 전진해 | 닫힌 동안 열기, 열린 뒤 전진 |

조건은 입력대로 평가한다. “보이면”은 현재 보임 조건이고 “길을 막으면”과 같다고 몰래 바꾸지 않는다. 한 번 동작했다는 이유로 조건을 거짓으로 만들지도 않는다. 물체의 보임·상태·적용 범위가 달라졌을 때만 다시 판단한다.

## 한 줄 안의 복합 행동

“밀고 올라가”처럼 사용자가 명시한 순서는 한 수칙 내부의 순서다. 그 수칙이 선택되는 동안 어디까지 했는지는 유지한다. 그래도 다음 행동 경계에서는 모든 메모의 우선순위를 다시 확인한다. 더 높은 수칙이 맞으면 그것을 실행하고, 낮은 수칙은 다시 선택됐을 때만 이어간다. 중단된 수칙이 새 우선순위 검사보다 먼저 자동 재개되면 안 된다.

바깥 조건이 바뀌면 그 조건과 분기도 다시 평가한다. 끝난 복합 수칙이 계속 맞으면 처음부터 다시 실행할 수 있다. `guard` 표식 유무가 우선순위를 다르게 만들지 않는다. 명시적 기다림·유지·동시 행동의 내부 규칙은 보존한다. 단순 조건문을 임의의 기다림으로 바꾸지 않는다.

## 저장과 AI

수칙 선택은 로컬 실행기가 담당한다. AI는 입력할 때만 문장·조건·행동을 구조화하며 실행 순서를 임의로 최적화하지 않는다. 재선택에는 추가 AI 호출이 없다. 현재 장면 전용 대상과 명시한 범용 수칙의 대상 결합은 구분한다. 다른 장면에 없는 물체를 임의의 물체로 바꾸지 않는다.

기존 저장의 메모·순서·작성권·지우개·데스·해금·재생 기록은 유지한다. 옛 실행기의 `completed` 기록은 수칙을 제외하는 근거로 사용하지 않는다. 이미 저장된 과거 행동은 새로운 규칙으로 재계산하지 않는다. 예전 완료 표식 때문에 “적용할 메모 없음”으로 멈춘 활성 실행은, 현재 맞는 수칙이 있으면 기록과 데스를 유지한 채 이어간다. 실제 물체에 막힌 상태는 이 복구 대상이 아니다.

새 1장은 서사 프롤로그를 읽거나 SKIP한 뒤 모두 1-1에서 시작하고, 1-6까지 첫 입력의 메모장을 이어 쓴다. 장면 이동은 메모·우선순위·지우개·데스·연혁을 초기화하거나 무료 작성권을 만들지 않는다. 죽은 뒤 장 입구에서 한 줄을 더 쓰며, 지우개 두 개를 쓴 뒤 삭제 비용은 한 줄당 3데스다. 우선순위와 지우개는 실제 메모 사용 시 짧게 안내한다. `layoutVersion`이 없거나 1인 진행 저장은 옛 도입과 여덟 방 경로를 유지한다. 새 시작·초기화는 `layoutVersion: 3`의 여섯 장면을 사용하며, 과거 완료 원본은 옛 좌표로 검증한 뒤 장별 완료·최고 기록 요약으로 전환한다.

## 변경 시 필수 회귀 기준

동일 수칙의 연속 재선택, 거짓 조건에서 아래 수칙 선택, 일반 조건 수칙의 높은 우선순위 개입, 무조건 전진의 우선순위 독점, 조건 변화 뒤 복합 행동 재선택, 이전 완료 표식이 있는 저장 복구를 검사한다. 1장의 기존 판단 규칙을 반대로 바꿔 후속 장에 맞추지 않는다. 장별 물리 풀이 검사만으로 이 규칙의 검증을 대신하지 않는다.

현재 신규 플레이는 스테이지 하나당 맵 하나다. 1-6의 다리를 통과하면 즉시 클리어하며 추가 가시·우회로 장면을 붙이지 않는다. 이전 버전 2의 활성 기록도 마지막 다리를 이미 건넜으면 기록을 유지한 채 완료 처리한다.

## 완료 기록의 보관 범위

완료 회차 목록·전체 재생·상세 실행본의 영구 누적은 제거한다. 장별 완료·해금·최고 점수와 마지막 완료 참조/시각만 남긴다. 현재 실행의 메모·사건·재생 기록은 조건 실행, 반복 연출, 발견 힌트, 저장 검증과 “방금 무슨 일이?”에 필요하므로 유지한다. 이전 완료 상세 데이터는 요약의 저장이 성공한 다음 정리하며 활성 복구 자료와 섞어서 지우지 않는다.

## 진전 없는 행동 반복

2~10장에서는 같은 수칙의 같은 행동이 용사·물체·장치·기억에 변화를 만들지 못한 채 3회 연속 반복되면 지쳐 쓰러지고 +1데스로 처리한다. 실제 이동·상태 변화가 있거나 순차 명령의 진행 위치·장치 주기가 달라지면 연속 횟수를 다시 센다. 시간 숫자가 증가하거나 같은 관찰을 다시 기록하는 것만으로는 진전으로 보지 않는다. 조건 대기는 기존 대기 판정을 사용한다.

예를 들어 2-1에서 “상자가 보이면 밀어”만 적으면 상자에 다가가 치우는 동안은 정상 실행하고, 치운 상자를 제자리에서 계속 밀 때 반복을 감지한다. 전진 수칙을 자동 추가하거나 낮은 우선순위 수칙을 대신 고르지 않는다. 사망 후에는 기존 메모를 유지하고 한 줄 추가·수정된 우선순위로 다시 시도한다. 진행 중 연속 횟수는 저장하며 이전 저장에 이 정보가 없으면 0회부터 센다.
