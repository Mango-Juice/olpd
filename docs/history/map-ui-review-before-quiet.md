# 맵 화면 검토 — 2026-09-22

## 발견한 문제

기획 문서, 68개 후속 장의 초기 월드, 실제 QA 화면을 대조했다. 기존 1장 본편의 8개 방은 별도 렌더러를 사용하며 이번 변경의 게임 규칙 수정 대상이 아니다.

- 5장 등의 서로 다른 방을 `x:y`만으로 묶어 같은 바닥에 섞어 그렸다.
- 9장 마지막 장면은 26개 물체를 960px에 압축했고, 이름 대신 번호를 표시했다. 별도 목록을 열기 전에는 물건을 알아보기 어려웠다.
- 물과 틈 아래에도 연속 바닥이 그려져 보행 가능한 땅처럼 보였다.
- 도입의 화살표·쐐기·바람개비·팔, 본편의 사다리·씨앗·배 등의 전용 형태가 빠져 일반 상자처럼 보였다.
- 닫힌 급수 장치의 설정 유량이 실제 흐름처럼 표시됐고, 깃발의 `fluttering` 상태를 사용하지 않았다.
- 캠페인 캐릭터는 항상 정지 자세였다. 소지·탑승·유지 상태와 화면상 물체의 위치가 충분히 연결되지 않았다.
- 1장 신규 도입의 옆길 곡선과 캐릭터 발 경로가 달랐고, 성공 종점이 문턱보다 앞에 있었다.

## 수정 기준

물리 규칙이나 정답을 바꾸지 않는다. 현재 공개된 물건과 상태만 그린다. 짧은 이름과 실제 상태를 먼저 보이고, 긴 설명과 세부 성질은 선택한 뒤 확인한다. 여러 방과 물건을 한 화면에 무리하게 축소하지 않고, 읽을 수 있는 크기의 지도를 좌우로 살펴볼 수 있게 한다. 물건 선택과 캐릭터 이동 때 해당 위치를 보여주되, 사용자가 살펴보는 동안 임의로 카메라를 되돌리지 않는다.

검증 스크립트: `pnpm exec tsx scripts/browser-map-readability.ts`. AI를 호출하지 않고 68개 장면의 렌더링, 물건 선택, 스크롤, 모바일 너비를 검사한다. 캡처와 결과는 git 제외 경로 `artifacts/map-readability/`에 보관한다.

## 공통 기준과 반영

사용자의 추가 피드백에 따라 프롤로그부터 최종장까지 1장 본편을 시각 품질 기준으로 삼았다.

- 원본 1장의 석조 아치·빛줄기·기둥·벽돌 바닥을 `drawDungeonBackdrop`, `drawDungeonFloor`, `drawDungeonMasonry`로 공유한다. 기존 본편의 경로와 규칙은 유지한다.
- 짧은 방도 화면 양끝까지 이어지고, 실제 물·틈만 바닥을 끊는다. 짧은 도입의 목표는 방의 가로 폭을 활용해 배치한다.
- 물체 이름은 14px 이상을 기준으로 표시하고, 문은 용사보다 큰 구조물로 그린다. 긴 맵은 가독성을 유지한 채 좌우 이동하며 전체 지도 보기로 구조를 확인한다.
- 방별 중력과 벽·천장 접촉을 구분한다. 모양은 중력에 맞춰 회전하되 이름은 똑바로 읽힌다.
- 실제 소지 물건, 탑승물, 고정 손잡이를 구분한다. 실행 기록의 선택적 `verb` 필드로 이동 자세를 표시하며, 이 필드는 물리 판정에 사용하지 않는다. 이전 저장도 허용한다.
- 같은 시도에서 물건이 움직일 때 장면 전체가 갑자기 재배치되지 않도록 투영을 유지한다. 숨은 물체는 이름·모양·연결에 포함하지 않는다.
- 정지·움직임 줄이기 상태에서는 상태·선택·크기·스프라이트 로드가 바뀔 때만 다시 그린다. 재생 중 화면 갱신은 약 30fps로 제한한다.

1장 신규 도입은 발과 샛길의 같은 경로, 장애물 근처에서만 점프·숙이기, 쿠션 착지, 문 안 도착을 적용했다. 이미지 로드 직후 임시 캐릭터 도형이 남던 문제도 수정했다.

## 최종 검증

- 전체 테스트: 50개 파일, 500개 테스트 통과. 68개 초기 맵의 이름표 경계·충돌, 물건 선택 좌표, 탑승·운반·고정 손잡이, 천장·벽에서 소지 물건의 경계를 포함한다.
- 타입 검사와 프로덕션 빌드 통과. 기존 단일 JS 청크 500kB 경고는 남아 있다.
- 실제 브라우저: 후속 장 68개 초기 맵에서 렌더링·물건 선택·가로 탐색·모바일 페이지 너비 검사 통과. 장면 좌·중·우 캡처를 저장했다.
- 1장 도입 4개 및 2장 도입 3개의 실행·재접속·본편 인계 브라우저 검사 통과. 해석 API 경계에는 fixture를 사용했으며 이번 UI 검증에서 유료 AI 호출은 하지 않았다.
- 원본 1장 본편의 게임 규칙과 기존 8개 방은 유지했다. 시각 검토 중 드러난 천장 화살표 방향과 고정 장치·운반물 구분도 수정했다.

이 검증은 초기 배치 전수 검사와 대표 행동·상태 검사다. 모든 가능한 사용자 지침으로 생기는 모든 중간 화면이나 사람의 재미 평가를 전수 검증한 것은 아니다. 복잡한 장면은 현재도 좌우 탐색이 필요하며, 전체 지도 보기는 구조 확인용으로 제공한다.
