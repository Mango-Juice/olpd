# 역사 문서 안내

이 폴더는 이전 설계안, 구현 상태, UI 검토, API 실험의 당시 내용을 보존한다. 여기에 남은 코드 경로·장면 수·프롬프트·검증 결과는 기록 작성 당시의 사실이며 현재 구현이나 현재 배포를 설명하지 않을 수 있다. 역사 기록의 본문과 수치는 과거 맥락을 위해 유지한다.

현재 기준은 아래 문서를 따른다.

- [캠페인 구현과 저장 계약](../campaign-implementation.md)
- [현재 장면 설계](../stage-design/README.md)
- [공통 플레이 계약](../stage-design/00-play-contract.md)
- [현재 요구사항과 구현 맵](../requirements.md)
- [API 계약](../api.md)
- [최신 검증 기록](../verification.md)

역사 설계에서 이전 코드로 이어지던 링크는 실제 과거 구현 파일 대신 `tests/fixtures/campaign-worlds/`의 보존된 물리 월드 fixture를 가리킨다. 이는 현재 게임 실행 코드가 아니다.
