# 1장 — 기억의 던전

> **도입 4개 로컬 구현 · 통합 검증은 [구현 기록](../campaign-implementation.md) 참고.** 기존 완성된 8개 방의 배치·순서·판단점·네 행동 의미는 그대로 둔다. 재미·플레이타임은 실측하지 않았다.
>
> 기준: [현재 방 배치](../../src/game/content.ts), [행동과 상태](../../src/game/types.ts), [현재 플레이 설명](../../README.md).

## 첫 행동부터 나누는 이유

입력·기억·죽음·새 위험을 한꺼번에 이해시키지 않는다. 1-1에서는 열린 문까지 한 걸음, 1-2에서는 바닥 틈 하나, 1-3에서는 낮은 아치 하나, 1-4에서는 연결 샛길 하나만 직접 통과한다. 문장을 쓰고 결과를 보는 같은 흐름을 반복하지만 매번 새로운 판단은 몸동작 하나뿐이다.

그 뒤 기존 `구덩이 → 모습이 다른 같은 위험 → 바닥 가시 → 낮은 천장 → 복합 위험과 샛길 → 연속 구간`을 그대로 진행한다. 몸동작을 처음 발견하는 부담을 덜고, 무엇을 조건으로 쓰며 어느 줄을 우선할지 본편에서 연결한다. 물건 조작은 2장부터다.

도입 4–6분과 기존 본편 15–25분을 합친 **19–31분**을 잠정 목표로 둔다. 실측이 아니며 설명 대기나 강제 사망으로 시간을 채우지 않는다. 기존 본편 저장은 도입을 면제해 이어 가며, 재학습은 선택이다.

## 프롤로그·본편 인계와 유지할 계약

- 새 도입 1-1~1-4가 기존 체험형 프롤로그의 자리를 대신한다. 강제 추락·부활·삭제 실습을 도입 전후에 중복 재생하지 않는다. 서사 프롤로그 SKIP은 유지하되 새 플레이의 정식 도입 완료와 별개다.
- 도입에는 단계마다 무료 임시 한 줄과 지역 복구가 있다. 완성한 문장은 도입 기록에 남기고 본편 활성 메모에 자동 복사하지 않는다. 무료 실패를 본편 데스로 세지 않는다.
- 신규 플레이는 1-5에서 **빈 본편 메모 + 무료 첫 작성 1회 + 사망/삭제 가산 0 + 지우개 2개**로 시작한다. 현재 `skipTutorial`과 같은 초기 경제를 새 인계에 쓰는 설계다. 첫 문장을 적고 출발하므로 강제 실패가 필요 없다.
- 기존 프롤로그에서 얻은 두 줄이나 본편 진행 메모는 새 문서 때문에 지우지 않는다. 기존 저장은 면제 표시로 이어 가고 허위 도입 완료 연혁을 추가하지 않는다.
- 기존 본편 행동은 전진·점프·숙이기·우회이며, 한 지침은 현재처럼 단일 행동과 적용 상황으로 해석한다. 다중 행동·도구·협력은 요구하지 않는다.
- 적용 가능한 줄 중 화면 위쪽 줄을 따르고 출발 전 순서 변경은 무료다. 적용 메모가 없으면 기존대로 전진한다. 새 위험 앞 자동 안전 정지를 기존 8방에 소급하지 않는다.
- Enter로 해석·기억·출발을 잇고, 사망 또는 자진 부활 뒤 한 줄 기회, 지우개 2개 이후 삭제 +3데스를 유지한다. 1-6~1-12 최초 도달마다 새 무료 줄을 주지 않는다.
- 본편 실패는 1-5의 기존 던전 입구로 돌아가고 메모는 남는다. 완료 도입까지 되감지 않으며 기존 재생 규칙을 따른다.
- 상세 무료 학습·면제·저장 경계는 [공통 인계 계약](00-play-contract.md#도입의-무료-학습과-본편-인계)을 따른다. 이 경계는 현재 프롤로그와 런 엔진에 로컬 구현되어 통합 검증 중이다.

## 진행 번호와 구현 경계

신규 도입은 **1-1~1-4**, 기존 구간은 **1-5~1-12**다. 화면에는 앞자리 0 없이 이 연속 번호를 쓴다. 아래의 옛 번호와 코드 식별자는 마이그레이션 대응용이며 새 화면 번호가 아니다. 도입 ID는 `first-step`, `single-gap`, `low-arch`, `side-path`이며 [레거시 온보딩 코드](../../src/game/onboarding.ts)에 있다.

기존 8개 방은 현재 완성된 별도 엔진의 내용이다. 원래 방의 배치·순서·네 행동 의미는 유지한다.

| 이전 문서 번호 | 현재 코드 ID / 위치 | 새 화면 번호 |
| --- | --- | --- |
| `01-1` | `ROOMS[0]` (방 배열, 별도 ID 없음) | 1-5 |
| `01-2` | `ROOMS[1]` (방 배열, 별도 ID 없음) | 1-6 |
| `01-3` | `ROOMS[2]` (방 배열, 별도 ID 없음) | 1-7 |

## 필수 도입 스테이지 — 1-1~1-4

각 단계는 별도 입장·목표·실행·완료 기록을 갖는다. 아래 대상 목록은 용사와 고정 배경을 제외하되 도달해야 하는 지점·관찰 목표를 포함한다. 연결 부품을 한 장치로 셌더라도 실제 보이는 부품을 적었다. 처음에는 1~2대상과 관계 하나만 두고, 늘어나는 경우 그 이유를 해당 카드에 명시한다. 무료 복구·본편 인계는 [공통 계약](00-play-contract.md#도입의-무료-학습과-본편-인계)을 따른다.

### 1-1. 한 걸음의 약속 — 정식 도입

- **배울 것 하나:** 자연어로 쓴 한 행동이 용사의 몸을 움직인다.
- **화면에 실제 보이는 대상:** 1개: 열린 문(이동 목표). 평평한 바닥 외에는 다른 대상이 없다.
- **시작 상태:** 용사는 짧은 돌길 앞에 정지하고 메모장은 빈 한 줄만 활성화된다.
- **목표:** 열린 문까지 걸어간다.
- **자연어 의도 예시:** “문 쪽으로 걸어가.” 같은 의도를 표현한 다른 문장도 인정하며 정답 문구로 제시하지 않는다.
- **기대 변화·완료 조건:** 전진이 실행되어 용사가 문턱에 닿으면 완료한다. 메모와 실제 발걸음의 대응만 강조한다.
  - **구현 검토:** 기존 네 행동의 의미를 보존하면 평지의 점프·숙이기도 앞으로 이동한다. 전진만 정답으로 강제하면 공통 규칙과 충돌하므로, 실제로 문턱에 도달한 안전한 이동을 완료로 인정한다. 샛길 없는 우회는 멈춘다.
- **실패·무료 회복:** 다른 이동을 써도 안전한 바닥에서 끝난다. 문에 못 닿았으면 같은 자리에서 무료로 다시 쓰며 자동 출발·자동 사망은 없다.
- **다음 스테이지와의 연결:** 다음 방에서 같은 문까지 가되 바닥에 작은 끊김 하나만 더 만난다.
- **아직 배치하지 않는 것:** 구덩이, 가시, 천장, 샛길, 물건, 다른 지침, 죽음·삭제 비용 설명.

### 1-2. 끊긴 바닥 하나 — 정식 도입

- **배울 것 하나:** 점프는 끊긴 바닥을 건너는 몸의 행동이다.
- **화면에 실제 보이는 대상:** 2개: 좁은 바닥 틈, 맞은편 문(이동 목표). 밑의 쿠션은 접근 대상이 아닌 실패 받침이다.
- **시작 상태:** 짧은 틈 앞에 정지한다. 높은 천장과 건너편 문까지의 거리가 한눈에 보인다.
- **목표:** 바닥 틈을 넘어 문에 닿는다.
- **자연어 의도 예시:** “바닥이 끊긴 곳에서는 뛰어넘어.” 같은 의도를 표현한 다른 문장도 인정하며 정답 문구로 제시하지 않는다.
- **기대 변화·완료 조건:** 현재 네 행동 중 점프로 틈을 넘고 문에 닿으면 완료한다. 정확한 명사나 조사 대신 관찰 조건과 행동을 연결한다.
- **실패·무료 회복:** 그냥 걸으면 쿠션에 내려앉고 틈 앞에 무료로 돌아온다. 실패를 반드시 보게 하지 않으며 첫 시도 성공도 동일하게 완료한다.
- **다음 스테이지와의 연결:** 점프가 필요한 상황을 경험한 뒤 다음 방에서는 머리 위 장애물 하나를 본다.
- **아직 배치하지 않는 것:** 다리 외형 변주, 가시, 낮은 천장, 샛길, 두 지침의 우선순위.

### 1-3. 머리 위 돌 — 정식 도입

- **배울 것 하나:** 숙이기는 낮은 통로에서 몸의 높이를 줄인다.
- **화면에 실제 보이는 대상:** 2개: 낮은 돌 아치, 아치 뒤 문(이동 목표).
- **시작 상태:** 바닥은 이어지고 아치의 높이가 선 용사의 머리보다 낮다. 앞 단계 메모는 기록에만 보관된다.
- **목표:** 낮은 돌 아치 아래로 지나간다.
- **자연어 의도 예시:** “머리 위가 낮으면 숙여서 지나가.” 같은 의도를 표현한 다른 문장도 인정하며 정답 문구로 제시하지 않는다.
- **기대 변화·완료 조건:** 숙인 용사가 아치를 지나 문턱에 닿으면 완료한다. 바닥 위험이나 다른 행동을 동시에 판단하지 않는다.
- **실패·무료 회복:** 서서 가거나 뛰면 둥근 아치 앞에서 멈추고 몸과 아치 높이를 보여 준다. 무료 수정 후 같은 시작점에서 다시 실행한다.
- **다음 스테이지와의 연결:** 다음 방은 막힌 정면 대신 옆길 하나를 고르는 장소다.
- **아직 배치하지 않는 것:** 바닥 틈, 가시, 이동 물건, 중력 전환, 두 지침의 경쟁.

### 1-4. 옆으로 난 길 — 정식 도입

- **배울 것 하나:** 우회는 실제로 연결된 샛길을 따라 움직인다.
- **화면에 실제 보이는 대상:** 2개: 막힌 정면과 연결 샛길을 가진 돌벽 지형, 그 뒤 문(이동 목표). 샛길은 별도 조작 물건이 아닌 동일 지형의 보행 경로다.
- **시작 상태:** 정면은 높고 두꺼운 돌벽이며 옆 샛길은 입구부터 출구까지 보인다.
- **목표:** 샛길을 따라 문까지 간다.
- **자연어 의도 예시:** “정면이 막히고 옆길이 있으면 옆길로 돌아가.” 같은 의도를 표현한 다른 문장도 인정하며 정답 문구로 제시하지 않는다.
- **기대 변화·완료 조건:** 우회 경로로 문에 닿으면 완료한다. 점프 가능한 높이나 새로운 물건 조작을 암시하지 않는다.
- **실패·무료 회복:** 정면으로 가면 돌벽 앞에서 멈춘다. 원하는 경로가 다르면 무료로 한 줄을 고쳐 다시 출발한다.
- **다음 스테이지와의 연결:** 네 행동을 모두 몸으로 해 본 뒤 1-5의 기존 구덩이 방으로 넘어간다. 이후에는 조건을 넓히고 충돌을 구분한다.
- **아직 배치하지 않는 것:** 위아래 복합 위험, 움직이는 장치, 도구, 우선순위 퍼즐.

## 기존 8개 방 — 배치와 순서 보존

### 1-5. 첫 번째 기억

- **현재 배치:** 구덩이 하나. 천장은 높고 샛길은 없다.
- **통과:** 구덩이를 점프해 넘는다.
- **생각할 점:** 보이는 위험을 조건으로 삼고, 실제 행동을 문장에 담는다.
- **제작자 참고 예문:** “앞에 구덩이가 있으면 뛰어넘어.” 정답 문구로 화면에 강제하지 않는다.
- **실패 해석:** 그냥 전진하면 바닥이 끊긴 곳으로 떨어진다. 어떤 지침을 따랐는지와 바닥 단절이 연결되어 보이는지 확인한다.
- **후반 회수:** 사건을 보고 대응하는 기본 단위. 2장에서 조건의 대상이 지형에서 물건으로 넓어진다.

### 1-6. 끊어진 약속

- **현재 배치:** 끊어진 다리 하나. 천장은 높고 샛길은 없다.
- **통과:** 끊어진 구간을 점프해 넘는다.
- **생각할 점:** ‘구덩이’라는 이름 하나보다 실제로 발밑 길이 끊겼다는 공통점이 중요하다. 앞 문장이 다른 모습의 위험에도 적용되는지 본다.
- **제작자 참고 예문:** “앞의 바닥이 끊겨 있으면 뛰어넘어.”
- **실패 해석:** 다리의 외형이 달라도 떨어지는 이유는 같다. 새 동사 대신 조건의 범위를 돌아보게 한다.
- **후반 회수:** 같은 성질을 다른 외형에 적용하는 2장의 물성 학습으로 이어진다.

### 1-7. 발밑의 반짝임

- **현재 배치:** 바닥 가시. 천장은 높고 샛길은 없다.
- **통과:** 가시를 점프해 넘는다.
- **생각할 점:** 점프라는 기존 행동을 다른 위험에 적용한다. ‘바닥이 끊김’과 ‘밟으면 위험함’의 조건 차이를 읽는다.
- **제작자 참고 예문:** “바닥에 가시가 있으면 뛰어넘어.”
- **실패 해석:** 길은 이어져 있지만 안전하게 밟을 수 없다. 위험의 이름과 위치를 함께 보게 한다.
- **후반 회수:** 5장의 일반 조건과 좁은 예외, 보스의 낮은 공격에 대한 판단으로 확장한다.

### 1-8. 고개를 낮추면

- **현재 배치:** 낮은 천장 가시. 바닥은 평평하고 샛길은 없다.
- **통과:** 몸을 숙여 지난다.
- **생각할 점:** 모든 위험에 점프하면 안 된다. 위험의 위치에 따라 대응이 달라진다.
- **제작자 참고 예문:** “천장 가시가 낮게 내려와 있으면 숙여서 지나가.”
- **실패 해석:** 넓은 점프 지침이 적용됐다면 실제로 따른 줄과 머리 위 가시를 함께 확인한다.
- **후반 회수:** 보스의 공격 높이와 장소별 위험을 구분하는 토대다.

### 1-9. 다른 길의 발견

- **현재 배치:** 구덩이와 낮은 천장 가시가 함께 있고 안전한 샛길이 보인다.
- **통과:** 샛길로 우회한다.
- **생각할 점:** 하나씩 안전했던 행동도 두 조건이 겹치면 위험하다. 복합 상황에 해당하는 지침을 위에 둘 필요가 생긴다.
- **제작자 참고 예문:** “발밑과 머리 위가 함께 위험하고 샛길이 있으면 그 길로 돌아가.”
- **실패 해석:** 점프는 천장과 충돌하고 숙이기는 끊어진 바닥을 해결하지 못한다. 기존 지침이 잘못됐다기보다 적용 범위가 넓다는 것을 이해하게 한다.
- **후반 회수:** 5장에서 물체 상태와 지역 조건까지 넓어지는 예외 처리의 첫 경험이다.

### 1-10. 작은 지름길

- **현재 배치:** 바닥 가시와 낮은 천장 가시, 안전한 샛길.
- **통과:** 샛길로 우회한다.
- **생각할 점:** 직전과 바닥의 모습은 달라도 ‘위아래가 위험하고 다른 길이 있음’이라는 관계는 같다.
- **실패 해석:** 앞 지침이 구덩이만 가리켰다면 조건을 다시 살핀다. 유일한 정답 단어를 외우게 하지 않는다.
- **후반 회수:** 외형이 달라진 같은 장치를 다시 알아보는 캠페인 전체의 기본이다.

### 1-11. 기억을 이어서

- **현재 배치:** 구덩이 → 낮은 천장 가시의 두 판단점.
- **통과:** 첫 지점에서 점프하고 다음 지점에서 숙인다.
- **생각할 점:** 한 줄에 두 행동을 새로 쓰는 시험이 아니다. 각 상황에서 이미 쓴 서로 다른 지침이 이어서 적용되는 것을 본다.
- **실패 해석:** 실패한 판단점의 조건과 적용 줄을 확인한다. 전체 방을 하나의 행동으로 처리하지 않는다.
- **후반 회수:** 여러 상황을 기존 지침으로 풀어 나가는 감각. 2장 이후 한 지침 안의 행동 순서로도 범위를 넓힌다.

### 1-12. 빛이 드는 곳

- **현재 배치:** 끊어진 다리 → 바닥 가시 → 낮은 천장 가시 → 구덩이·천장 가시·샛길 → 위아래 가시·샛길 → 평평한 길.
- **통과:** 점프 → 점프 → 숙이기 → 우회 → 우회 → 전진. 이는 제작자용 판정 확인 순서이지 사용자에게 보여 줄 선택 목록이 아니다.
- **생각할 점:** 새 기믹 없이 지금까지 만든 조건과 우선순위가 전체 구간에서 함께 통하는지 확인한다.
- **실패 해석:** 어느 조건이 다른 지침에 가려졌는지 실제 적용 줄로 추적한다.
- **성취:** 자신이 만든 메모만으로 긴 구간을 통과한다. 이 자신감을 가진 상태에서 2장의 새로운 가능성을 보여 준다.
- **후반 회수:** 보스도 같은 원리로, 처음 보는 정답을 요구하기보다 이전 장에서 배운 관계를 조합한다.

## 장의 BGM 분위기 — 제작 제안

- **대표 분위기:** 낯선 던전이지만 서두를 필요 없는 작은 산책. 따뜻함 사이에 아주 약한 쓸쓸함을 남기고, 위험물 첫 노출부터 불안한 전투 음악을 쓰지 않는다.
- **음색:** 현재 1장의 느린 68 BPM, 따뜻한 5도 화음과 드문 짧은 선율을 출발점으로 삼는다. 둥근 건반·부드러운 종의 여운을 중심으로, 용사의 발걸음과 메모장 넘기는 소리가 들어갈 빈 공간을 둔다. 이는 신규 편곡 방향이며 새 음원이 만들어졌다는 뜻은 아니다.
- **도입 → 본편 → 절정:** 1-1~1-4는 같은 짧은 선율을 한두 음색으로 잇고, 1-5부터 낮은 화음이 천천히 받친다. 1-12에서만 선율의 마지막 구절을 조금 넓혀 메모로 긴 길을 통과한 성취를 만든다. 단계마다 새 곡으로 끊지 않는다.
- **반복과 집중:** 사망마다 곡 첫머리를 다시 울리거나 실패 화음을 덧씌우지 않는다. 입력 중에는 긴 잔향과 낮은 화음만 남길 수 있으며, 멜로디가 다음 행동이나 정답을 재촉하지 않는다.

같은 장의 도입·본편·절정은 공통 모티프와 음색을 이어 쓴다. 실제 작곡·음원 생성·오디오 구현은 이번 문서 작업에 포함되지 않으며, [공통 음악 원칙](00-play-contract.md#음악과-실제-장치-신호)을 따른다.

## 에셋·연출 방향

현재 [아트 디렉션](../art-direction.md)을 유지한다. 보랏빛 석조 아치, 민트 샛길, 바닥과 천장의 가시 실루엣, 목재 끊어진 다리, 크림색 몸과 민트 후드의 용사다. 상자·판자·쐐기 세트와 새로운 조작 모션을 이 장 때문에 추가하지 않는다.

기존 걷기·점프·숙이기·우회·사망·부활·성공 연출과 실제 적용 메모 강조를 활용한다. 색보다 바닥 단절, 천장 높이, 가시 방향, 샛길 연결이 먼저 읽혀야 한다. 1-12(기존 8번 방)의 마지막 평평한 길에서 긴 설명 없이 다음 장의 빗소리와 젖은 돌바닥이 이어진다.

## 선택적 복선과 2장으로의 연결

첫 장 끝의 종 받침에 작은 민트빛 그을음 정도만 제안한다. 진행 조건이나 새 퍼즐로 쓰지 않는다. 2-1에서는 마른 바닥의 상자 하나를 옮기며 물체 접촉부터 시작하고, 2-2에서 처음 물에 띄운다.

## 유지 확인 기준

- `src/game/content.ts`의 8개 방 이름·순서·판단점과 이 문서가 일치한다.
- 기존 1장 통과 지침이 캠페인 문서 때문에 실패하거나 추가 도구 조작을 요구하지 않는다.
- 1-11과 1-12은 현재처럼 여러 판단점의 지침 선택으로 진행하며 다중 행동 파서의 도입 조건이 아니다.
- 새 캠페인의 구간별 발견 한 줄·도구·협력·관측 기억 규칙을 기존 8방에 소급하지 않는다. 새 인계의 무료 첫 작성 1회만 위와 같이 명시한다.
- 2장은 1장에서 물건 조작을 배웠다고 가정하지 않는다.
