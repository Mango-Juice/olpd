# 구현 검증 기록

## 2026-09-23 — 영구 메모 수칙과 우선순위 교정 (로컬)

사용자 확인에 따라 메모를 일회성 작업 목록으로 취급하던 동작을 교정했다. [공통 메모 수칙](game-rules.md)이 현재 기준이다. 아래 과거 기록 중 “지시를 모두 마치면 정지”, 완료 표식에 따른 실행 제외, guard만 선점한다는 가정은 폐기한다.

- 매 판단 경계에서 화면 위에서부터 조건을 재평가해 첫 수칙을 선택한다. 실행 완료로 소모하지 않는다. 이동 도중의 다음 걸음에도 상위 수칙이 개입할 수 있다. 거짓인 바깥 조건은 아래 수칙으로 넘어가고, 확인할 수 없는 조건은 임의로 건너뛰지 않는다.
- 한 줄 내부의 명시적 순서·동시 행동·대기는 유지한다. 중단된 순서는 다시 선택됐을 때만 이어간다. 끝난 수칙이 계속 맞으면 다시 실행한다. 무조건 전진을 맨 위에 두면 아래 상자 조건을 가리는 것도 의도한 결과다.
- 이전 `completed` 표식은 후보 제외에 쓰지 않는다. 이 표식 때문에 메모 없음으로 멈춘 활성 실행은 맞는 수칙이 있으면 메모·데스·과거 기록을 유지한 채 재개한다. 물리적 충돌 정지는 자동으로 풀지 않는다.
- AI 프롬프트를 지속 수칙으로 맞췄고 버전을 `campaign-deepseek-20-persistent-rules`로 올렸다. 단순 조건문은 `if`, 명시한 기다림만 `wait`로 표현한다. 실행할 때 AI를 다시 호출하지 않는다. 사전 검사는 한 수칙의 전체 실행을 확인한 뒤 끝내며, 반복 때문에 512번 재검사하지 않는다.
- 전체 **70개 파일 822개 검사**, 타입 검사·빌드 통과. 현재 54개 공간 장면 풀이도 통과했다. 과거 fixture의 소모형 기대는 새 규칙으로 고쳤고, 명시적으로 여러 지역을 건너는 과거 복합 풀이의 적용 범위도 그 의도에 맞췄다.
- `npx tsx scripts/browser-persistent-rules.ts`: 전진 우선이면 상자 충돌, 상자 조건 우선이면 점프 후 천장 충돌, 성공한 밀기 수칙 재선택·새로고침, 예전 메모 소모 정지의 0데스 복구를 실제 브라우저에서 확인했다. API 호출 0회.
- `npm run test:browser`: 기존 도입 Enter·IME·취소·오류·재개·인계 및 후속 장 공용 메모장·부활·우선순위·지우개 흐름 통과. 응답 fixture 검사이며 실제 모델 자연어 정확도를 재측정한 것은 아니다.

이번 변경에 앞서 추가한 공용 “이 장 처음부터” 버튼은 장 전체 메모·데스를 초기화하며, 취소·다른 장 보존·1장 도입 복구와 모바일을 10개 장에서 확인했다. “부활하고 · +1데스” 문구를 공통으로 적용했다. QA에서 1장 도입을 다시 시작한 저장이 새로고침 뒤 사라지던 슬롯 판정·오래된 상태 덮어쓰기도 수정했다. 배포·push·유료 호출은 하지 않았다.

- 브라우저: 실제 상자·천장 구분, 재생 종료 뒤 힌트, 다음 생·새로고침 중복 방지, 모바일, 1장 도입, 7-5 공동 운반, 10-5 높이 부족 확인. 54개 장면과 9개 장 모바일에서 고정 폭·가로 넘침 없음 확인. 대표 화면도 직접 열어 검토했다.

## 2026-09-23 — 자동 전진 제거 (로컬)

## 2026-09-23 — 포기 직후 재생 지연 수정 (로컬)

포기에는 실제 행동 이벤트가 없는데 일반 재생 길이 4.2초와 70% 이후 사망 연출이 적용돼 약 2.94초 정지처럼 보였다. 행동 없는 포기 재생은 즉시 사라지기 시작해 650ms(동작 줄이기 350ms)에 끝나도록 분리했다. 버튼 선택 시 남은 일시정지도 해제한다. 포기 자막에는 기본 전진 문구를 표시하지 않으며, 기본 전진의 표시는 시스템 행동임을 명시했다. 기본 이동 규칙과 사망·작성권 정책은 변경하지 않았다.

전체 780개 검사·빌드 및 공용 캠페인 브라우저 검사 통과. 브라우저 검사는 포기 선택 후 2.2초 이내 작성창 복귀와 포기 전용 자막을 확인한다. API는 명시적 fixture 2개를 사용했으며 유료 호출은 없다.

실제 Jev 입력 5회로 튜토리얼부터 본편 8개 방까지 26개 이벤트, 3데스로 클리어했다. 입력 후 별도 출발 버튼 없이 진행되는 흐름, 새로고침 비용 중복 방지, 튜토리얼 기록 이월, 다른 탭 충돌 정지, 공유 선택, 모바일 가로 넘침을 확인했다. 이 Chromium 실행에서 본편 6,294프레임 평균 60fps, 25ms 초과 0프레임이었다. 기기 전체의 성능 보장은 아니다.

별도 실제 AI 검증에서 “구덩이가 있으면 전진해”는 기존 “구덩이가 있으면 뛰어”와 같은 `pit/bridge/pitCeilingPath` 집합으로 해석됐다. API 해석은 200이지만 메모 충돌 가드가 저장을 막았고, 원래 저장 데이터와 초안·작성 기회가 유지됐다. 화살표로 이전 전진 메모를 맨 위로 옮기면 실제 구덩이 판정에서도 그 메모가 선택된다.

모바일 삭제 취소, 지우개 두 개 뒤 +3 비용, 삭제 후 기존 구간 판정 변경, 설정 저장, 실제 클립보드 공유도 통과했다. 통신/저장 실패와 IME Enter, 390×430 키보드 높이 모의 검증은 `v2-local-browser-errors-report.json`에 있다.

데스크톱 네이티브 드래그와 모바일 CDP 터치 입력으로 최하단 메모를 최상단에 옮겨 실제 저장 순서와 revision +1을 확인했다. 화살표로 원순서를 복원할 수 있고 비용·작성 기회·사건 기록은 변하지 않았다. 삭제 버튼은 네 줄 모두 상시 표시되며 `···` 메뉴에는 선택한 한 줄의 화살표만 나타난다. 메모장의 회전을 제거한 뒤 데스크톱/모바일의 버튼 오른쪽 좌표 편차는 모두 0px였다. CDP 터치 검사는 실제 휴대전화에서 한 검사와 구분한다.

## 음악 검증

실제 Web Audio를 계측했다. 14.60초 관찰에서 14.1176초 루프 경계를 넘어 첫 16개 음원 뒤 다음 16개가 예약됐다. 동일 스테이지 재생 요청을 반복해도 중첩하지 않았다. 일시정지 시 예약 음 16개 중지, 재개 시 재예약, 음소거 시 master gain이 약 0으로 내려가며 AudioContext는 하나를 유지했다. 숨김/복귀도 중지/재예약됐으나 이 부분은 headless에서 `document.hidden`과 이벤트를 모사한 검사다. 청감의 선호도는 자동화 결과로 주장하지 않는다.

## AI 입력 가드 및 기존 운영 검증

이번 작업에서 서버 해석 모델·임계값·API 본문 스키마는 바꾸지 않았다. 이전 실제 Jev 평가의 고정 합성 지침 85개 결과는 적용 조합 371/371, 전체 집합 53/53, 거부 입력 32/32, 튜토리얼·대표 문장 11/11이었다. 개발 중 보정한 평가 세트이며 전체 한국어 정확도나 독립 평가 성과가 아니다. 원본은 `docs/jev-evaluation-2026-09-21.md`에 있다.

이전 공개 HTTP 검증에서 연쇄 행동 문장, 무적, 데스 0 변경은 422 unsupported, 모호한 “그게 있으면 뛰어”는 422 uncertain이었다. 현재 메모의 정확한 조건 집합 충돌은 이 서버 가드 이후 `core.addInstruction`에서 별도로 검사한다. 기존 메모 원문을 서버에 보내지 않는다.

전진·점프·숙이기·우회는 아직 전역 공통 행동이다. 자유로운 발화 시점·강도·대상과 장별 행동 확장은 설계 제안이며 이번 코드 변경에 포함하지 않았다. 스토리는 `docs/story-concept.md`의 제안 문서만 작성했다.

기존 Vercel 프로젝트의 `/api/interpret` WAF는 IP별 30회/60초, 서버 인스턴스 제한도 병행한다. 이전 실제 GET 35회에서 31번째부터 429였다. 리전별 고정 윈도이며 전역 비용 상한은 아니다. 키는 서버 환경변수에만 두고 `AI_ENABLED=false`로 공급자 호출을 중단한다. 운영 로그는 모델·버전·토큰·지연·오류 코드만 남긴다. 이번 작업은 이 설정을 변경하지 않았다.

## 근거와 관찰 경계

`artifacts/`는 Git/공개 배포에서 제외한다.

- `v2-local-browser-report.json`: 실제 전체 플레이와 프레임/오디오 계측
- `v2-local-priority-report.json`: 수동 순서, 실제 판정 변화, 실제 AI 충돌 거부
- `drag-report.json`, `drag-desktop.png`, `drag-mobile.png`: 네이티브/터치 드래그, 상시 삭제, 동일 우측 정렬
- `v2-local-notebook-report.json`: 삭제·공유·설정
- `v2-ui-report.json`: 가독성, 말풍선, 장면별 재생, 중복 문구 제거
- `v2-music-check.mjs`, `v2-music-report.json`: 실제 오디오 루프/정지/음소거
- `olpd-v3-all-poses.png`, `olpd-v3-walk-*.png`: 새 캐릭터 포즈와 걷기
