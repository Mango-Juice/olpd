실제 Web Audio를 계측했다. 14.60초 관찰에서 14.1176초 루프 경계를 넘어 첫 16개 음원 뒤 다음 16개가 예약됐다. 동일 스테이지 재생 요청을 반복해도 중첩하지 않았다. 일시정지 시 예약 음 16개 중지, 재개 시 재예약, 음소거 시 master gain이 약 0으로 내려가며 AudioContext는 하나를 유지했다. 숨김/복귀도 중지/재예약됐으나 이 부분은 headless에서 `document.hidden`과 이벤트를 모사한 검사다. 청감의 선호도는 자동화 결과로 주장하지 않는다.

## AI 입력 가드 및 기존 운영 검증

이번 작업에서 서버 해석 모델·임계값·API 본문 스키마는 바꾸지 않았다. 이전 실제 Jev 평가의 고정 합성 지침 85개 결과는 적용 조합 371/371, 전체 집합 53/53, 거부 입력 32/32, 튜토리얼·대표 문장 11/11이었다. 개발 중 보정한 평가 세트이며 전체 한국어 정확도나 독립 평가 성과가 아니다. 원본은 `docs/jev-evaluation-2026-09-21.md`에 있다.

이전 공개 HTTP 검증에서 연쇄 행동 문장, 무적, 데스 0 변경은 422 unsupported, 모호한 “그게 있으면 뛰어”는 422 uncertain이었다. 현재 메모의 정확한 조건 집합 충돌은 이 서버 가드 이후 `core.addInstruction`에서 별도로 검사한다. 기존 메모 원문을 서버에 보내지 않는다.

전진·점프·숙이기·우회는 아직 전역 공통 행동이다. 자유로운 발화 시점·강도·대상과 장별 행동 확장은 설계 제안이며 이번 코드 변경에 포함하지 않았다. 스토리는 `docs/story-concept.md`의 제안 문서만 작성했다.

기존 Vercel 프로젝트의 `/api/interpret` WAF는 IP별 30회/60초, 서버 인스턴스 제한도 병행한다. 이전 실제 GET 35회에서 31번째부터 429였다. 리전별 고정 윈도이며 전역 비용 상한은 아니다. 키는 서버 환경변수에만 두고 `AI_ENABLED=false`로 공급자 호출을 중단한다. 운영 로그는 모델·버전·토큰·지연·오류 코드만 남긴다. 이번 작업은 이 설정을 변경하지 않았다.

## 근거와 관찰 경계

`artifacts/`는 Git/공개 배포에서 제외한다.

- `v2-local-browser-report.json`: 실제 전체 플레이와 프레임/오디오 계측
- `v2-local-priority-report.json`: 수동 순서, 실제 판정 변화, 실제 AI 충돌 거부
- `drag-report.json`, `drag-desktop.png`, `drag-mobile.png`: 네이티브/터치 드래그, 상시 삭제, 동일 우측 정렬
- `v2-local-notebook-report.json`: 삭제·공유·설정
- `v2-ui-report.json`: 가독성, 말풍선, 장면별 재생, 중복 문구 제거
- `v2-music-check.mjs`, `v2-music-report.json`: 실제 오디오 루프/정지/음소거
- `olpd-v3-all-poses.png`, `olpd-v3-walk-*.png`: 새 캐릭터 포즈와 걷기
- `olpd-final-fork-*.png`: 최종 두 갈래 길의 분기·뒤편 횡단·합류, 모바일 표현

모바일 결과는 Chromium 화면과 입력 에뮬레이션이다. 실제 iOS/Android 기기, 사람 대상 첫 플레이 이해도, 실제 플레이 소요 시간은 별도 관찰이 필요하다.
