# 2~5장 첫 접촉 안내 검토

`spatial-v1` 장면 정의와 몸통 충돌 판정을 대조했다. `추가`는 해당 장면의 새 관찰, `재사용`은 이미 배운 현상을 같은 `key`로 한 번만 보여 줄 후보, `불필요`는 입장 목표와 장면 자체로 충분한 경우다. 접촉 문구는 실패·막힘 이벤트의 `motion.contact.entity`에 실제 기록된 몸체에만 붙인다. 상호작용 힌트는 실제 접근을 거친 `interact` 이벤트의 대상과 typed issue를 확인한다. 낙하 힌트는 별도 장면 관측으로만 선택한다. 목표 문자열이나 명령 대상만으로 접촉을 추정하지 않는다.

| 장면 | 판단 | 근거와 정확한 트리거 |
| --- | --- | --- |
| 2-1 막힌 빗길 | 추가 `box-moves` | 출구로 걷다 `02-v2-1-box` 단단한 몸통에 막힌다. 상자 옆 빈자리를 관찰한다. 낮은 천장 접촉은 공통 천장 문구를 쓴다. |
| 2-2 높은 창 | 추가 `box-supports`, `window-high` | 상자 몸통 `02-v2-2-box` 접촉은 발판 성질을, 창 벽 `02-v2-2-window` 접촉은 높이를 알려 준다. 창까지 가기 전에 단차에서 떨어지는 경우엔 두 번째 문구를 내지 않는다. |
| 2-3 끊긴 바닥 | 추가 `plank-spans` | `02-v2-3-plank` 몸통과 충돌하면 길이를 관찰한다. 틈으로 떨어지는 사건은 `fall`에 접촉 물체가 없으므로 널빤지를 만난 척하지 않는다. 실제 낙하 뒤에는 틈 양쪽 돌턱을 관찰하는 별도 문구를 같은 `plank-spans` 발견으로 묶는다. |
| 2-4 떠 있는 발판 | 추가 `floating-platform` | `02-v2-4-pool` 물 몸통에 닿으면 고정된 코르크 발판이 떠 있는 것을 관찰한다. 코르크는 움직이는 승강판이 아니며, 발판에 안전하게 올라서는 동작에는 실패 안내가 필요 없다. |
| 2-5 잠긴 아래 계단 | 추가 `drain-water` | `02-v2-5-pool`의 활성 물 몸통에 닿으면 물 밖 배수 덮개를 발견한다. 물이 빠진 뒤에는 몸통이 비활성이므로 안내하지 않는다. |
| 2-6 처진 다리 | 추가 `bridge-support` | `02-v2-6-box` 몸통에 막히면 다리 아래 빈 받침 자리를 관찰한다. 지지 후 나타나는 `bridge` 몸통은 안전한 통행면이며 새 문구가 필요 없다. |
| 3-1 숨 쉬는 배출구 | 추가 `steam-pulse` | 활성 `03-v2-1-steam` 몸통과 접촉했을 때 김이 멎는 박자를 관찰한다. |
| 3-2 오븐의 박자 | 추가 `oven-opens` | 닫힌 `03-v2-2-oven` 몸통에 막혔을 때 문이 열리는 박자를 관찰한다. 열린 뒤엔 몸통이 비활성이다. |
| 3-3 오르내리는 집게 | 추가 `claw-rises` | 낮아진 `03-v2-3-claw` 몸통과 접촉한 경우 아래쪽에 생길 틈을 관찰한다. |
| 3-4 부푸는 디딤돌 | 추가 `rising-dough` | `03-v2-4-dough` 몸통에 막히면 윗면이 오르는 변화를 관찰한다. 맨바닥에서 선반으로 바로 못 오르는 무접촉 실패에는 반죽 접촉 문구를 내지 않는다. |
| 3-5 다가오는 쟁반 | 추가 `moving-platform` | `03-v2-5-tray` 몸통에 닿으면 이동·정지 패턴을 관찰한다. 구덩이로 그냥 떨어질 때는 `fall`에 접촉 물체가 없다. 실제 낙하 뒤에는 쟁반이 가까워질 때 발을 옮길 수 있다는 장면 관측을 같은 발견으로 보여 준다. |
| 3-6 김 사이의 배달 | 재사용 `steam-pulse`, `moving-platform` | `03-v2-6-steam` 또는 `03-v2-6-tray`의 실제 접촉에만 앞서 배운 현상을 짧게 상기한다. 낙하에는 쟁반 타이밍의 장면 관측을 사용하고, 김 접촉에는 김 문구만 고른다. 같은 장에서 이미 같은 `key`를 보았다면 반복하지 않는다. |
| 4-1 잠든 풍차 | 추가 `windmill-guard` | `04-v2-1-windmill` 망 몸통은 바닥보다 위에 있어 걷기만으로는 접촉하지 않는다. 점프해 망에 실제 충돌한 경우에만 문구를 낸다. 대상에 실제 접근한 상호작용 실패에도 같은 발견 후보를 사용할 수 있다. |
| 4-2 바람 승강판 | 추가 `wind-lift` | `04-v2-2-lift` 판의 측면에 닿았을 때 풍낭과 바람관 연결을 관찰한다. 높은 출구를 향하다 단차에서 떨어지는 무접촉 실패에는 쓰지 않는다. |
| 4-3 뜨거운 길 | 추가 `hotplate-cools` | 냉각 전 활성 `04-v2-3-hotplate` 열 몸통에 닿았을 때 송풍기 바람으로 식힐 가능성을 관찰한다. 냉각 뒤 비활성 몸통에는 반복하지 않는다. |
| 4-4 회전날개 통로 | 추가 `spinning-blades` | `04-v2-4-blades` 몸통에 닿으면 바람길과 회전의 관계를 관찰한다. 멈춰 올라간 상태에서도 점프 충돌이 가능하므로 문구에서 현재 회전 상태를 단정하지 않는다. |
| 4-5 붙잡아 둔 바람 | 추가 `spring-door` | 닫힌 `04-v2-5-door` 몸통에 막히면 벽 홈과 걸쇠의 관계를 관찰한다. 실제 접근한 상호작용이 실패한 경우에도 같은 발견을 사용할 수 있다. |
| 4-6 이어진 바람 | 재사용 `wind-lift` | `04-v2-6-lift` 판 측면 접촉에만 풍낭과 바람관 연결을 관찰한다. 4-2에서 같은 승강판 안내를 봤다면 반복하지 않는다. 높은 출구 도달 실패만으로 판 접촉을 추정하지 않는다. |
| 5-1 천장의 산책 | 불필요 | 몸통 충돌체가 없고 걷기가 곧 목표다. 입장 목적과 위로 향한 시각 단서면 충분하다. |
| 5-2 천장의 가시 | 추가 `ceiling-thorns` | `05-v2-2-thorns` 가시 몸통에 닿았을 때 아래쪽 열린 공간을 관찰한다. 반전 중력 점프 명령까지 미리 알려 주지 않는다. |
| 5-3 낮은 덩굴 | 추가 `low-vine` | 점프해 `05-v2-3-vine` 가시 몸통에 닿으면 아래의 통행 공간을 관찰한다. 평범하게 걸으면 접촉하지 않으므로 문구가 뜨지 않는다. |
| 5-4 잠든 꽃 | 추가 `low-shelf`, `floor-thorns` | 점프 중 `05-v2-4-shelf` 돌시렁 접촉은 낮은 높이를, 걷다 `05-v2-4-thorn` 가시꽃 접촉은 열린 위쪽을 관찰한다. 한 사건에서 실제 부딪힌 물체의 문구만 낸다. |
| 5-5 중력 문턱 | 추가 `low-arch`, 재사용 `ceiling-thorns` | 아치 안에서 점프해 `05-v2-5-arch` 몸통에 부딪히면 좁은 높이를 관찰한다. 천장 가시 `05-v2-5-thorns` 접촉은 5-2와 같은 `key`다. 아치의 걷기 전환은 별도 접촉 안내가 필요 없다. |
| 5-6 정원의 출구 | 재사용 `low-vine`, `floor-thorns` | 점프 중 `05-v2-6-vine` 접촉 또는 걷다 `05-v2-6-thorns` 접촉에만 해당 관찰을 낸다. 각각 5-3, 5-4에서 배웠다면 다시 띄우지 않는다. |

첫 접촉 문구는 한 실패당 하나가 적당하다. 선택기는 현재 장의 전체 6개 장면을 검색하고, 저장된 이벤트 이력에서 아직 배우지 않은 가장 최근 발견 하나를 고른다. 실제 접촉은 접촉 엔티티, 상호작용은 기록된 대상·typed issue, 낙하는 장면 낙하 관측으로 구분한다. 접촉하지 않은 낙하에 상자·널빤지 등 물체 접촉을 꾸며 붙이지 않는다.
