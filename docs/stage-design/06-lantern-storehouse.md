# 6장 — 등불 보관소

> 현재 설계 v2 · 6장면 · 기준 화면 960×500. 코드와 검증 상태는 별도로 확인한다. 이전 복합 설계는 [역사 기록](../history/stage-design-v1/README.md)이며 구현 요구사항이 아니다.

## 장의 중심 — 놓고 다시 챙긴다

물건은 사라지는 토큰이 아니라 눈앞에서 들고 놓는 실물이다.

[공통 플레이 계약](00-play-contract.md)을 따른다. 현재 장면에서 무료로 문장을 고치고 다시 해 본다. 이미 마친 장면을 다시 통과할 필요는 없다. 이전 장의 설명서나 물체 속성표를 읽어야 풀리는 장면은 만들지 않는다.

## 사용자에게 보이는 문구

입장할 때 아래 목적 한 문장을 한 번 보여 주고 구분에 필요한 사물 이름만 남긴다. 확인 팝업은 없다. 명령 예시, 요소 역할, 세부 완료 판정과 해법은 개발자용 정보이며 UI에 표시하지 않는다. 해야 할 일은 알리되 해결 순서는 말하지 않는다.

| 장면 | 입장 목적 한 문장 |
| --- | --- |
| 6-1 어둠에 가져가기 | 벽감을 밝혀야 해요. |
| 6-2 두 손으로 오르기 | 위 선반에 올라가야 해요. |
| 6-3 두고 가지 않기 | 등불과 함께 다음 방으로 가야 해요. |
| 6-4 빌리는 열쇠 | 열쇠를 가지고 문 너머로 가야 해요. |
| 6-5 같은 열쇠 | 두 문 너머로 가야 해요. |
| 6-6 불빛을 챙겨서 | 등불과 함께 보관소를 나가야 해요. |

## 제작·검증용 장면 명세

아래 수와 역할은 내부 설계 검증용이다. 도착점·위험·관찰 대상·조작 물건을 모두 세며, 일반 바닥과 배경 장식만 제외한다. 연결된 물건을 묶어 수를 숨기지 않는다. 용사와 등지기는 수에서 제외하지만 등지기의 별도 역할은 인지 부담으로 검토한다.

### 6-1. 어둠에 가져가기

- **요소 2개:** 등불 — 휴대, 어두운 벽감 — 목표.
- **공간:** 왼쪽 아래의 등불과 오른쪽 위 벽감을 짧은 비탈이 잇는다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 등불을 벽감으로 가져간다.
- **최소 의도 예시 — 사용자 비노출:** “등불을 들고 벽감으로 가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 소지 위치. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 불빛이 용사와 함께 이동해 벽감을 밝힌다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 6-2. 두 손으로 오르기

- **요소 4개:** 등불 — 휴대, 벽고리 — 임시 보관, 사다리 — 양손 길, 위 선반 — 목표.
- **공간:** 벽고리는 사다리 옆, 위 선반에서도 닿는 높이에 놓인다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 위 선반에 오른다.
- **최소 의도 예시 — 사용자 비노출:** “등불을 고리에 걸고 올라가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 손을 비우기. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 등불이 손에서 고리로 옮겨지고 두 손으로 사다리를 잡는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 6-3. 두고 가지 않기

- **요소 3개:** 등불 — 휴대, 벽고리 — 현재 위치, 출구 — 목표.
- **공간:** 앞 장면의 위 선반에서 고리가 바로 옆에 보인다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 등불과 함께 출구에 닿는다.
- **최소 의도 예시 — 사용자 비노출:** “등불을 챙겨 출구로 가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 회수. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 고리가 비고 손에 든 등불이 출구까지 따라간다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 6-4. 빌리는 열쇠

- **요소 3개:** 열쇠 — 휴대 도구, 자물쇠문 — 잠긴 장벽, 출구 — 목표.
- **공간:** 왼쪽 열쇠에서 중앙 문, 오른쪽 출구로 짧은 길이 이어진다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 문을 열고 열쇠와 함께 지난다.
- **최소 의도 예시 — 사용자 비노출:** “열쇠로 문을 열고 챙겨 가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 사용해도 남는 도구. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 열쇠를 돌린 뒤 다시 손에 챙기고 문은 열린 채 남는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 6-5. 같은 열쇠

- **요소 4개:** 열쇠 — 유일 도구, 아래문 — 잠긴 장벽, 위문 — 잠긴 장벽, 출구 — 목표.
- **공간:** 아래 중앙 문을 통과한 길이 오른쪽 위 문으로 굽어 오른다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 두 문을 연다.
- **최소 의도 예시 — 사용자 비노출:** “아래문을 열고 열쇠로 위문도 열어.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 회수와 재사용. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 같은 열쇠가 첫 문에서 나와 두 번째 문으로 이동한다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 6-6. 불빛을 챙겨서

- **요소 4개:** 등불 — 휴대, 열쇠 — 도구, 문 — 잠긴 장벽, 출구 — 목표.
- **공간:** 등불은 왼쪽, 열쇠는 중앙 문 바로 옆, 출구는 오른쪽이다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 등불과 함께 열린 문을 지난다.
- **최소 의도 예시 — 사용자 비노출:** “문을 열고 등불을 챙겨 나가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 도구와 가져갈 물건의 구별. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 열린 문을 지나갈 때 등불이 손에 있다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

손이 필요한 행동은 실제 몸동작으로 드러난다. 슬롯 수, 무게 등급, 수량 계산 패널은 없다. 6-2의 고리는 위에서도 손이 닿는 높이에 배치하고 6-3은 그 결과를 포함해 시작한다. 열쇠는 사용 후 돌아오며, 다른 장소에 복제되지 않는다. 편지는 주머니의 서사 소품으로 손이나 운반 자원을 차지하지 않는다.

## 이야기와 장의 음악

두 사람 몫의 낡은 찻잔. “하나는 늘 돌아올 사람 몫으로 비워 두었다.”

이야기 소품은 장면 완료 뒤 짧은 선택 장면으로 보여 준다. 퍼즐 화면의 상호작용 대상이나 숨은 조건으로 추가하지 않는다. 모루와 편지, 등지기의 기존 서사 연결과 용사의 외형은 유지한다.

- **대표 분위기:** 늦은 시간 작은 등불을 켜고 물건을 챙기는 차분함. 부족한 자원에 쫓기기보다 놓인 위치를 하나씩 돌보는 따뜻한 집중이다.
- **음색:** 펠트 피아노, 낮은 목재 울림, 얇은 유리 잔향. 금속 열쇠와 고리 체결은 효과음에 맡기고 음악은 둥글고 가라앉은 소리로 구별한다.

여섯 장면은 같은 장의 모티프를 이어 쓴다. 첫 장면은 성기게, 마지막에는 음색을 조금 모으되 실제 장치 소리와 구분한다. 실패 때 곡을 처음부터 재생하거나 음악으로 정답을 알려 주지 않는다. 음소거에서도 움직임과 인과를 모두 읽을 수 있다. 음악 제작 제안이며 새 음원 구현을 뜻하지 않는다.

## 이 장의 검증 경계

- 960×500 안에서 필수 요소와 출발·결과가 동시에 보이며 화면 밖 대상이나 가로 스크롤이 없다.
- 목적 한 문장 이외의 설명 없이도 무엇이 막혔고 행동 뒤 무엇이 바뀌었는지 몸·공간·움직임으로 읽힌다.
- 최초 장면은 한두 의도로 끝나고, 후반 재회도 긴 문장이나 물리 계산을 요구하지 않는다.
- 장면별 이름·요소 수·인과가 실제 렌더링과 일치한다. 장식으로 보이는 숨은 정답 물체가 없다.
- 실패 뒤 현재 장면만 다시 하며 문장 수정 비용과 앞 장면 재플레이가 없다.
- 플레이 시간과 재미는 사람 플레이로 검증하기 전까지 수치 성과로 주장하지 않는다.
