# 10장 스테이지 설계 — 한 줄로 바꾸는 던전

> **설계 제안 / 미구현.** 2026-09-22 요청에 따른 10장 캠페인이다. [스토리 콘셉트](../story-concept.md)의 종·메모장·편지·길잡이·문지기를 이어받고, 기존 5장 예시를 확장한다. 현재 구현은 여전히 네 행동과 8개 방이다. 여기의 해법·플레이타임·재미는 구현 또는 사용자 테스트로 검증되지 않았다.

## 핵심 방향

플레이어가 만드는 것은 **상황을 읽고 세계에 변화를 일으키는 한 문장**이다. 문장은 버튼 네 개를 대신 누르는 입력창에서 벗어난다. 무엇을 대상으로, 무엇을 이용해, 언제 시작하고 끝낼지, 무엇을 남길지를 직접 정한다.

예를 들어 “물이 무서우면 우회해”보다 “빈 나무통을 물에 띄우고, 그 위에 올라 반대편 난간까지 가”가 이 캠페인의 방향이다. 빈 통의 부력, 실리는 무게, 닿는 거리와 물의 흐름이 화면에 있어야 한다. 해석기는 문장을 이해하고, 세계의 규칙이 결과를 결정한다. 정답으로 등록된 문구와 닮았는지는 판정 기준이 아니다.

- **문장의 길이보다 관계의 수를 늘린다.** 대상 → 물성 → 시간 → 상태 → 예외 → 자원 → 협력 → 관찰 기억 순으로 생각할 거리가 늘어난다.
- **움직임 외의 해결을 허용한다.** 장애물을 바꾸거나, 도구를 놓거나, 작동 시간을 늦추거나, 다른 주체에게 역할을 맡겨도 된다.
- **2장부터 확장 행동을 단계별 잠금 없이 허용한다.** “기다려”는 2장에서도 이해한다. 3장은 기다릴 이유와 끝낼 기준을 배울 장소다. 기존 1장은 현재의 네 행동 해석을 유지한다.
- **한 줄에 여러 행동을 써도 된다.** 동시에 실행하는 것과 차례로 실행하는 것은 구별한다. 긴 절차가 필요한 방은 중간 성취를 두어 나눈다.
- **안내는 사실을 준다.** “밧줄 끝이 이 고리에 닿는다”는 관찰이다. “당기기·밀기·묶기 중 골라”는 안내를 쓰지 않는다.
- **스토리를 읽지 않고도 모든 방을 푼다.** 필수 기계 정보와 선택적 복선은 시각적으로 구분한다.

## 전체 흐름

**1장은 현재의 8개 방을 그대로 유지한다.** 네 행동과 기존 메모 학습을 마친 뒤 2장부터 새로운 상호작용을 추가한다.

2장 이후 각 구간 첫 도달의 안전 책갈피에서 새 한 줄을 쓸 수 있고, 실패하면 추가 수정 기회를 얻는다. 새 문제에 도전하기 위해 일부러 죽을 필요가 없도록 한 캠페인 규칙 확장안이다.

2~9장의 다섯 구간은 `안전한 발견 → 응용 → 익숙한 해법의 한계 → 조합 → 장의 절정`을 기본 리듬으로 삼는다. 10장은 3개 봉인에 걸친 6개 비트로 마무리한다. 기존 1장 8개 방을 포함해 총 **54개 설계 구간**이며, 구간을 실제 방 몇 개로 나눌지는 구현 단계에서 조정한다.

| 장 | 장소 / 주된 사고 | 새로 중요해지는 문장의 부분 | 절정과 최종 보스에 남길 것 | 초회 목표 시간 |
| --- | --- | --- | --- | --- |
| [01 기억의 던전](01-memory-dungeon.md) | 현재 8개 방의 관찰·조건·예외 | 어떤 상황에서 어떻게 움직일지 | 기존 메모의 적용과 우선순위 | 15–25분 |
| [02 비에 잠긴 회랑](02-rain-corridor.md) | 처음 물건을 조작하고 성질 활용하기 | 무엇을, 어디로, 무엇을 이용해 | 부력·지지·통로 확보 | 20–30분 |
| [03 태엽 부엌](03-clockwork-kitchen.md) | 사건을 기준으로 기다리기 | 언제, 무엇이 될 때까지 | 공격 사이의 안전한 창 읽기 | 20–30분 |
| [04 바람 대장간](04-wind-forge.md) | 먼저 환경을 바꾸기 | 무엇을 바꾼 뒤 | 적의 힘을 장치의 동력으로 쓰기 | 25–35분 |
| [05 뒤집힌 정원](05-inverted-garden.md) | 일반 규칙과 예외 구분하기 | 이 경우에는, 다만 | 보호해야 할 조건과 우선순위 | 25–35분 |
| [06 등불 보관소](06-lantern-storehouse.md) | 자원을 쓰고 되찾기 | 무엇을 남기고, 회수해서 | 제한된 도구의 역할 교대 | 25–35분 |
| [07 평형 인형극장](07-counterweight-theatre.md) | 다른 주체와 역할 나누기 | 누가 하는 동안 누가 | 유지와 이동을 함께 성립시키기 | 30–40분 |
| [08 안개 신호장](08-fog-signal-yard.md) | 확인한 사실을 기억해 적용하기 | 아까 본, 확인한 뒤 | 가려지기 전에 경로와 신호 읽기 | 30–40분 |
| [09 종탑의 안쪽](09-inner-bell-tower.md) | 여러 방을 하나의 장치로 보기 | 앞에서 만든 상태를 이어 | 최종 보스의 모든 기계 규칙 예행연습 | 30–40분 |
| [10 돌아오지 못한 문지기](10-returnless-warden.md) | 힘을 피하고, 돌리고, 함께 풀기 | 지금까지 배운 관계의 조합 | 세 봉인을 풀고 반복을 끝내기 | 30–45분 |

초회 합계 목표는 **250–355분, 약 4–6시간**이다. 읽기·관찰·실패 후 수정은 포함하고 장시간 방치와 선택 재도전은 제외한다. 이는 분량 배분 가설이며 실측이 아니다. 시간을 늘리기 위해 강제 사망, 반복 이동, 긴 대사를 넣지 않는다. 이미 원리를 아는 재플레이는 크게 짧아져도 좋다.

## 문서 읽는 순서

1. [공통 플레이·문장·공정성 규칙](00-play-contract.md)을 먼저 본다.
2. 각 장 문서에서 초기 배치, 목표, 해법 계열, 실패 피드백을 함께 본다. 예문은 제작자 참고이며 플레이 화면의 정답 목록이 아니다.
3. 9장과 10장을 함께 보며 보스에 미학습 규칙이 끼어들지 않았는지 확인한다.

공통 규칙과 장별 예시가 충돌하면 공통 규칙을 기준으로 장면을 수정한다. 구현 시 현재 게임의 단일 행동 해석·사망·저장 구조를 그대로 재사용할 수 있다고 가정하지 않는다. 이 폴더는 새 캠페인의 제품 설계이며, API나 데이터 구조를 확정하는 기술 명세가 아니다.

## 출시 판단을 위한 핵심 질문

- 플레이어가 “그 단어를 써야 했구나”보다 “그 물건을 그렇게 쓸 수 있었구나”라고 말하는가?
- 성공 문장에서 대상·순서·조건 중 하나를 바꾸면 실제 결과도 설명 가능하게 달라지는가?
- 2장 이후의 대표 퍼즐마다 다른 인과관계의 해법이 둘 이상 실제로 성립하는가? 같은 점프의 동의어 두 개는 두 해법이 아니다.
- 실패 직후 무엇이 달랐는지 보이고, 한 줄의 수정 또는 우선순위 조절로 다음 가설을 시험할 수 있는가?
- 보스의 해법을 떠올릴 때 앞선 장의 경험이 돌아오는가? 새 설명서가 필요하면 앞 장에서 가르친다.
- 스토리와 선택 힌트를 모두 건너뛰어도 해결 가능한가?

정답률·체류 시간·개발 난도에 맞춰 이 구성을 축소하기 전에 먼저 사람의 실패 이유를 관찰한다. 해석 실패, 화면 정보 부족, 물리 규칙 오해, 추론의 어려움은 서로 다른 수정 대상이다.
