# 10장 스테이지 설계 v4 — 공간과 접촉의 재구성

> **구현 연결:** 현재 게임은 `spatial-v1` 공간 실행기를 사용한다. 이 문서는 장별 연출·배치의 제작 기준이며, 실제 코드와 검증 범위는 [공간 실행기 v4](../spatial-implementation.md)에 구분한다. 수치 초안과 사람의 난이도 평가는 자동화 통과로 확정하지 않는다.

장 콘셉트와 이야기는 이어가고, 2~10장의 장치·배치·진행을 다시 만든다. **1장 12개 + 2~10장 각 6개 = 66개 장면**이다. 이전 80장면과 복합 물리 설계는 [역사 기록](../history/stage-design-v1/README.md)으로 분리하며 현재 요구사항으로 사용하지 않는다.

모든 새 장면은 **960×500 고정 구도**, **필수 요소 4개 이하**, **한 상황과 한 초점**을 따른다. 가로 스크롤, 확대해서 물체 찾기, 물체 카드 나열을 사용하지 않는다. 사용자는 짧은 목적을 입장 때 한 번 보고 한 줄을 입력해 즉시 행동을 본다. 해결 방법은 공간과 결과로 알아간다.

[공통 플레이 계약](00-play-contract.md)이 장별 예시보다 우선한다. 장 문서의 목표 판정·요소 역할·명령 예시는 개발자용이며, 별도 표에 있는 입장 목적 한 문장만 사용자에게 표시한다. 2장부터도 1장과 같은 누적 메모·죽음 뒤 한 줄·장 입구 재시작을 사용한다.

초반도 의도한 행동을 발견하고 써야 한다. 같은 한 줄로 학습 주제를 모두 건너뛰게 하지 않되, 실패 이유는 보이는 공간과 접촉으로 설명한다. 장별 구성에는 대안 행동의 결과와 물체별 예고·접촉·실패 연출을 포함한다.

1장의 기존 8개 방을 긴 물건 퍼즐로 바꾸지 않는다. 2~10장도 옛 A/B 해법이나 물리 수치를 유지하려고 요소를 추가하지 않는다. 한 장면의 요소를 세기 어려울 정도로 복잡해지면 장면부터 나눈다. 장면은 작아도 생은 장 전체를 잇고, 메모장을 장면마다 초기화하지 않는다.

모루·편지·등지기의 기존 이야기와 장별 음악 정서는 보존한다. 음악 제작 제안과 실제 음원 구현, 문서 변경과 코드 검증, 자동화 통과와 사람의 플레이 결과는 각각 구분해 보고한다. 기존 예상 플레이 시간은 새 설계의 실측치가 아니므로 옮기지 않는다.

## 구현 전에 남은 확인

- 장별 좌표·거리·높이는 배치 가설이다. 하나의 용사 충돌체·점프 궤적·도달 범위를 먼저 정한 뒤 모든 장에 같은 기준으로 검증한다. 맞지 않는 장면은 배치를 고치며 장마다 캐릭터 능력을 몰래 바꾸지 않는다.
- [8-1 안개 속 다리](08-fog-signal-yard.md)는 관찰 동사 검사 없이 시야와 경로 선택으로 성립해야 한다. 명시적인 전진 지시가 자동으로 안전한 길을 골라 관찰을 생략하지 않는지, 새 시야 규칙과 공통 이동 프로토타입에서 먼저 확인한다. 현재는 명시한 다리 경로와 명시적인 직진 지시의 난간 충돌을 자동 검사한다. 안개 윤곽의 가독성과 사람의 경로 발견은 별도 확인 대상이다.
- 3-6은 쟁반을 타는 이유가 보이도록 틈을 네 번째 요소로 명시했다. 4-5→4-6의 바람과 6-2→6-3의 등불은 실제 이전 결과를 넘겨야 하므로 구현 시 저장·재생·대안 풀이 인계를 함께 검증한다.
