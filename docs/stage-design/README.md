# 10장 스테이지 설계 — 차근차근 알아가는 던전

> **개정 기획 / 신규 도입 미구현.** 2026-09-22 요청에 따라 각 장의 기존 첫 스테이지 앞에 실제로 플레이하는 정식 도입을 추가했다. 기존 54개 구간과 해법은 유지하고 도입 26개를 더해 **총 80개 설계 스테이지**다. 이는 현재 구현 개수가 아니다. 기존 1장 8방은 완성, 2~6장은 프로토타입, 7장은 실험, 8~10장은 미구현이며 새 도입은 모두 설계만 있다. 재미·플레이타임은 사용자 테스트로 검증하지 않았다.

첫 화면에서 해야 할 일은 짧은 한 문장, 직접 신경 쓸 대상은 한두 개다. 다음 단계는 방금 해 본 행동에 새 관계 하나만 더한다. 복잡한 장면을 접힌 안내 뒤에 둔 채 시작하지 않고 실제로 다른 작은 방에서 몸을 움직여 배운 뒤 기존 퍼즐에 들어간다.

## 핵심 방향

플레이어가 만드는 것은 **상황을 읽고 세계에 변화를 일으키는 한 문장**이다. 문장은 버튼 네 개를 대신 누르는 입력창에서 벗어난다. 무엇을 대상으로, 무엇을 이용해, 언제 시작하고 끝낼지, 무엇을 남길지를 직접 정한다.

예를 들어 “물이 무서우면 우회해”보다 “빈 나무통을 물에 띄우고, 그 위에 올라 반대편 난간까지 가”가 이 캠페인의 방향이다. 빈 통의 부력, 실리는 무게, 닿는 거리와 물의 흐름이 화면에 있어야 한다. 해석기는 문장을 이해하고, 세계의 규칙이 결과를 결정한다. 정답으로 등록된 문구와 닮았는지는 판정 기준이 아니다.

- **관계를 하나씩 직접 익힌 다음 연결한다.** 대상 → 물성 → 시간 → 상태 → 예외 → 자원 → 협력 → 관찰 기억 순으로 생각할 거리가 늘어난다.
- **움직임 외의 해결을 허용한다.** 장애물을 바꾸거나, 도구를 놓거나, 작동 시간을 늦추거나, 다른 주체에게 역할을 맡겨도 된다.
- **2장부터 확장 행동을 단계별 잠금 없이 허용한다.** “기다려”는 2장에서도 이해한다. 3장은 기다릴 이유와 끝낼 기준을 배울 장소다. 1장 도입과 기존 8방은 현재 네 행동의 의미를 유지한다.
- **한 줄에 여러 행동을 써도 된다.** 동시에 실행하는 것과 차례로 실행하는 것은 구별한다. 긴 절차가 필요한 방은 중간 성취를 두어 나눈다.
- **안내는 사실을 준다.** “밧줄 끝이 이 고리에 닿는다”는 관찰이다. “당기기·밀기·묶기 중 골라”는 안내를 쓰지 않는다.
- **스토리를 읽지 않고도 모든 방을 푼다.** 필수 기계 정보와 선택적 복선은 시각적으로 구분한다.

## 전체 흐름과 번호

각 장의 도입은 새 플레이의 필수 진행이며 별도 입장·목표·행동·완료·다음 장면을 갖는다. 1장에서는 네 행동을 하나씩, 2~8장에서는 그 장의 새로운 관계를 나누어 해 본다. 9~10장은 이미 배운 관계를 현재 공간에서 짧게 재확인한다. 기존 2~9장 다섯 퍼즐의 발견·응용·비틀기·조합·절정과 10장 세 봉인/여섯 비트는 도입 뒤에 그대로 온다.

화면 번호는 장마다 `1-1`, `1-2`처럼 1부터 연속이다. 현재 코드 ID와 이전 문서 번호는 각 장의 대응표에 보존했다. 예를 들어 현재 `04-1`은 새 화면 **4-3**, 기존 `ROOMS[0]`은 **1-5**다. 이번 문서 변경만으로 저장 ID나 코드 카탈로그가 바뀐 것은 아니다.

## 학습 비용과 기존 플레이 보존

도입은 실패·수정·지역 복구가 무료이며 완료 기록을 남긴다. 임시 노트는 참고 기록으로 보관하고 본편 활성 메모에 자동 복사하지 않는다. 기존 첫 퍼즐에 들어가면 그 배치로 본편 복귀점을 저장하므로 실패 때 도입을 반복하지 않는다. 도입 재생으로 본편 지우개·작성 기회·종을 초기화할 수 없다.

1장 신규 플레이는 1-5에서 빈 본편 메모와 무료 첫 작성 1회로 시작한 뒤 기존 경제를 따른다. 새 도입이 옛 체험형 프롤로그를 대체하므로 강제 죽음·삭제 실습을 중복하지 않는다. 서사 프롤로그 SKIP은 학습 완료와 별개다. 기존 진행·완료 저장과 이미 얻은 메모는 보존하고 입문 면제로 표시하며, 플레이하지 않은 도입의 완료 기록은 만들지 않는다.

2~9장 기존 본편의 발견 기회는 장마다 최대 5회, 10장 기존 여섯 비트는 최대 6회다. 도입 수만큼 본편 메모 기회를 늘리지 않는다. 10장 봉인 복귀점은 10-3/10-5/10-7이며 도입과 분리한다. 상세 충돌 해결은 [도입·본편 인계](00-play-contract.md#도입의-무료-학습과-본편-인계)를 따른다.

## 장별 BGM 방향

아래는 **10장별 음악 제작 제안**이다. 스테이지 80개에 각각 다른 곡을 요구하지 않는다. 각 장의 같은 모티프를 도입에서는 성기게, 본편에서는 관계가 들리게, 절정에서는 음색과 화음이 모이게 쓴다. 음악은 시간 판정 신호가 아니며 음소거해도 플레이 정보는 같다. 구체적인 도입·절정 변화와 반복 원칙은 각 장 문서에 적었다.

## 문서 읽는 순서

1. [공통 플레이·학습·공정성 규칙](00-play-contract.md)을 먼저 본다.
2. 각 장의 번호 대응표와 도입 카드에서 실제 대상·목표·무료 회복·아직 배치하지 않는 것을 확인한다.
3. 기존 퍼즐의 해법·불변식·보스 회수를 이어 읽는다. 예문은 제작자 검토용이며 정답 목록이 아니다.
4. 9장과 10장을 함께 보며 선택 연습에만 있는 필수 지식이나 미학습 규칙이 끼어들지 않았는지 확인한다.

공통 규칙과 장별 예시가 충돌하면 공통 규칙에 맞춰 장면을 수정한다. 이 폴더는 제품 설계이며 API나 저장 구조를 확정하는 기술 명세가 아니다. 현재 엔진의 장 시작 복귀·프롤로그·메모·번호 계약을 그대로 쓰면 새 설계와 충돌하므로 별도 구현과 호환성 검증이 필요하다.

## 출시 판단을 위한 핵심 질문

- 신규 플레이어가 첫 단계에서 눈앞의 한두 대상과 한 문장 목표만 설명할 수 있는가?
- 단계마다 실제 행동 뒤 새 관계 하나를 알아내며, 기존 첫 퍼즐에 들어가기 전에 그 관계를 직접 써 보았는가?
- 도입에 장치가 추가됐다는 이유로 다음 복합 퍼즐을 더 어렵게 만들지 않았는가?
- 플레이어가 단어 정답보다 물건과 상태의 관계로 성공·실패 이유를 설명하는가?
- 2장 이후 주요 퍼즐마다 인과가 다른 두 해법이 실제로 성립하는가? 도입은 한 계열이어도 된다.
- 무료 도입을 끝내고 본편에 들어갔을 때 비용·복귀점·활성 노트 경계가 분명한가?
- 기존 저장을 열어도 진행과 메모가 남고, 실패 뒤 도입 반복이나 무료 지급 파밍이 없는가?
- 보스에서 앞선 장의 경험이 돌아오며, 스토리·선택 연습·힌트를 건너뛰어도 풀리는가?

학습 부하를 UI 접기로 해결했다고 간주하지 않는다. 사람의 실패를 해석 오류, 화면 정보 부족, 물성 오해, 조합 추론으로 나누어 관찰하고 실제 배치를 조정한다.
