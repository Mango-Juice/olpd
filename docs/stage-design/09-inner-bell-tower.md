# 9장 — 종탑의 안쪽

> 현재 설계 v3 · shared-v1 · 6장면 · 기준 화면 960×500. 코드와 검증 상태는 별도로 확인한다. 이전 복합 설계는 [역사 기록](../history/stage-design-v1/README.md)이며 구현 요구사항이 아니다.

## 장의 중심 — 배운 일을 짧게 잇는다

새 기본 규칙 없이 이미 익힌 관계를 작은 장면으로 다시 만난다.

[공통 플레이 계약](00-play-contract.md)을 따른다. 메모는 장 입구에서 시작한 한 생 동안 장면을 건너 누적·실행된다. 실패하면 장 입구로 돌아가 한 줄을 추가하며, 이전 장의 설명서나 물체 속성표를 읽어야 풀리는 장면은 만들지 않는다.

## 사용자에게 보이는 문구

입장할 때 아래 목적 한 문장을 한 번 보여 주고 구분에 필요한 사물 이름만 남긴다. 확인 팝업은 없다. 명령 예시, 요소 역할, 세부 완료 판정과 해법은 개발자용 정보이며 UI에 표시하지 않는다. 해야 할 일은 알리되 해결 순서는 말하지 않는다.

| 장면 | 입장 목적 한 문장 |
| --- | --- |
| 9-1 기울어진 층계 | 탑의 위층으로 올라가야 해요. |
| 9-2 종추의 틈 | 종추 너머로 가야 해요. |
| 9-3 이어진 풍로 | 다음 층으로 올라가야 해요. |
| 9-4 어두운 층계 | 등불을 가지고 층계를 올라가야 해요. |
| 9-5 서로 기다리는 층 | 등지기와 건너편에서 만나야 해요. |
| 9-6 종 위의 문 | 함께 종 너머의 문에 닿아야 해요. |

## 제작·검증용 장면 명세

아래 수와 역할은 내부 설계 검증용이다. 도착점·위험·관찰 대상·조작 물건을 모두 세며, 일반 바닥과 배경 장식만 제외한다. 연결된 물건을 묶어 수를 숨기지 않는다. 용사와 등지기는 수에서 제외하지만 등지기의 별도 역할은 인지 부담으로 검토한다.

### 9-1. 기울어진 층계

- **요소 3개:** 받침 — 이동, 기울어진 계단 — 길, 위층 — 목표.
- **공간:** 중앙 상승 계단 밑에 받침을 넣을 빈자리가 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 계단을 받쳐 오른다.
- **최소 의도 예시 — 사용자 비노출:** “받침을 넣고 올라가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 지지의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 계단이 수평으로 놓이고 용사가 오른다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 9-2. 종추의 틈

- **요소 2개:** 종추 — 주기 위험, 출구 — 목표.
- **공간:** 중앙 진자가 좌우로 움직이며 길을 가린다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 종추가 비킨 길을 지난다.
- **최소 의도 예시 — 사용자 비노출:** “종추가 비키면 지나가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 사건의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 추가 반대쪽으로 간 뒤 용사가 길을 지난다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 9-3. 이어진 풍로

- **요소 3개:** 바람판 — 조작, 종탑 승강대 — 운반, 위층 — 목표.
- **공간:** 왼쪽 아래 바람판에서 중앙 승강대, 오른쪽 위 층으로 이어진다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 승강대로 위층에 오른다.
- **최소 의도 예시 — 사용자 비노출:** “바람을 보내 승강대를 타.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 상태 유지의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 바람이 유지되는 동안 승강대가 위층에 닿는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 9-4. 어두운 층계

- **요소 3개:** 등불 — 휴대, 어두운 계단 — 길, 출구 — 목표.
- **공간:** 계단이 위로 굽어 오르고 등불은 시작점에 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 등불과 함께 계단을 오른다.
- **최소 의도 예시 — 사용자 비노출:** “등불을 챙겨 계단으로 가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 소지와 관찰의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 빛과 용사가 함께 올라가며 다음 발판이 보인다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 9-5. 서로 기다리는 층

- **요소 3개:** 유지 손잡이 — 조작, 연결 다리 — 길, 합류 자리 — 공동 목표.
- **공간:** 왼쪽 손잡이, 중앙 다리, 오른쪽 합류 자리가 하나의 동선이다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 등지기가 받친 다리를 건너 함께 합류한다.
- **최소 의도 예시 — 사용자 비노출:** “등지기는 내가 건널 때까지 잡아줘.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 협력의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 용사가 건너면 다리 끝의 일체형 톱니가 맞물리고 등지기도 따라온다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 9-6. 종 위의 문

- **요소 3개:** 관측창 — 관찰, 움직이는 종 — 주기 위험, 문 — 목표.
- **공간:** 창으로 종 옆 길을 확인하며 문까지의 전체 공간을 한 화면에 담는다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 길을 확인하고 종이 비킬 때 함께 간다.
- **최소 의도 예시 — 사용자 비노출:** “길을 보고 종이 비키면 함께 가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 관찰 뒤 대기의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 가려진 길의 윤곽을 본 뒤 종이 비킨 자리로 둘이 지난다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

종탑 전체를 한꺼번에 보여 주는 조작 지도는 없다. 9-5 다리 끝의 고정 톱니는 다리와 분리되지 않는 형상이지만 자동 고정은 사전에 눈으로 예상 가능해야 한다. 9-6도 별도 동료 명령 체계나 추가 자원을 도입하지 않는다.

## 이야기와 장의 음악

난간의 작은 메모. “이번에는 네가 먼저 종을 울렸네.”

이야기 소품은 장면 완료 뒤 짧은 선택 장면으로 보여 준다. 퍼즐 화면의 상호작용 대상이나 숨은 조건으로 추가하지 않는다. 모루와 편지, 등지기의 기존 서사 연결과 용사의 외형은 유지한다.

- **대표 분위기:** 지나온 방들이 하나의 탑으로 이어지는 조용한 확신. 결전을 재촉하기보다 자신이 익힌 관계를 믿고 한 층씩 올라간다.
- **음색:** 낮은 목관 오르간, 오래 울리는 현, 앞 장의 나무·유리 음색을 소량 재사용한다. 각 장의 선율을 한꺼번에 인용하지 않고 같은 짧은 주제의 음색만 교대한다.

여섯 장면은 같은 장의 모티프를 이어 쓴다. 첫 장면은 성기게, 마지막에는 음색을 조금 모으되 실제 장치 소리와 구분한다. 실패 때 곡을 처음부터 재생하거나 음악으로 정답을 알려 주지 않는다. 음소거에서도 움직임과 인과를 모두 읽을 수 있다. 음악 제작 제안이며 새 음원 구현을 뜻하지 않는다.

## 이 장의 검증 경계

- 960×500 안에서 필수 요소와 출발·결과가 동시에 보이며 화면 밖 대상이나 가로 스크롤이 없다.
- 목적 한 문장 이외의 설명 없이도 무엇이 막혔고 행동 뒤 무엇이 바뀌었는지 몸·공간·움직임으로 읽힌다.
- 최초 장면은 한두 의도로 끝나고, 후반 재회도 긴 문장이나 물리 계산을 요구하지 않는다.
- 장면별 이름·요소 수·인과가 실제 렌더링과 일치한다. 장식으로 보이는 숨은 정답 물체가 없다.
- 실패는 현재 생의 기록을 남기고 장 입구로 돌아가며, 누적 메모와 우선순위와 지우개는 유지된다.
- 플레이 시간과 재미는 사람 플레이로 검증하기 전까지 수치 성과로 주장하지 않는다.
