# 5장 — 뒤집힌 정원

> 현재 설계 v2 · 6장면 · 기준 화면 960×500. 코드와 검증 상태는 별도로 확인한다. 이전 복합 설계는 [역사 기록](../history/stage-design-v1/README.md)이며 구현 요구사항이 아니다.

## 장의 중심 — 익숙한 행동에 짧은 예외

중력과 위험의 위치를 눈으로 보고 상황에 맞는 행동을 고른다.

[공통 플레이 계약](00-play-contract.md)을 따른다. 현재 장면에서 무료로 문장을 고치고 다시 해 본다. 이미 마친 장면을 다시 통과할 필요는 없다. 이전 장의 설명서나 물체 속성표를 읽어야 풀리는 장면은 만들지 않는다.

## 사용자에게 보이는 문구

입장할 때 아래 목적 한 문장을 한 번 보여 주고 구분에 필요한 사물 이름만 남긴다. 확인 팝업은 없다. 명령 예시, 요소 역할, 세부 완료 판정과 해법은 개발자용 정보이며 UI에 표시하지 않는다. 해야 할 일은 알리되 해결 순서는 말하지 않는다.

| 장면 | 입장 목적 한 문장 |
| --- | --- |
| 5-1 천장의 산책 | 천장 길 끝으로 가야 해요. |
| 5-2 천장의 가시 | 가시 너머로 가야 해요. |
| 5-3 낮은 덩굴 | 덩굴 너머로 가야 해요. |
| 5-4 잠든 꽃 | 꽃밭을 지나가야 해요. |
| 5-5 중력 문턱 | 아치 너머의 길 끝으로 가야 해요. |
| 5-6 정원의 출구 | 편지와 함께 정원을 나가야 해요. |

## 제작·검증용 장면 명세

아래 수와 역할은 내부 설계 검증용이다. 도착점·위험·관찰 대상·조작 물건을 모두 세며, 일반 바닥과 배경 장식만 제외한다. 연결된 물건을 묶어 수를 숨기지 않는다. 용사와 등지기는 수에서 제외하지만 등지기의 별도 역할은 인지 부담으로 검토한다.

### 5-1. 천장의 산책

- **요소 2개:** 거꾸로 난 길 — 지형, 출구 — 목표.
- **공간:** 용사와 출구가 모두 천장에 붙어 있고 빈 공간은 아래다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 천장 길 끝에 닿는다.
- **최소 의도 예시 — 사용자 비노출:** “천장 길을 따라가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 공개된 중력 방향. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 후드와 흙가루가 위로 처지고 발은 천장 길을 딛는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 5-2. 천장의 가시

- **요소 2개:** 가시덤불 — 위험, 출구 — 목표.
- **공간:** 천장 중앙의 가시 양옆에 안전한 길이 이어진다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 천장의 가시를 넘는다.
- **최소 의도 예시 — 사용자 비노출:** “가시를 뛰어넘어.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 점프는 딛는 면에서 멀어짐. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 아래쪽으로 짧은 포물선을 그려 가시를 넘는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 5-3. 낮은 덩굴

- **요소 2개:** 덩굴 — 상부 위험, 출구 — 목표.
- **공간:** 바닥 길 위로 덩굴이 낮게 내려왔지만 걸을 높이는 남아 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 덩굴 아래를 지난다.
- **최소 의도 예시 — 사용자 비노출:** “덩굴 아래는 걸어가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 점프 대신 걷는 예외. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 용사가 뛰지 않고 머리 위 빈 공간을 따라 걷는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 5-4. 잠든 꽃

- **요소 3개:** 닫힌 꽃 — 무해한 바닥 물체, 가시꽃 — 위험, 출구 — 목표.
- **공간:** 굽은 길 위에 낮은 닫힌 꽃과 뾰족한 가시꽃을 떨어뜨려 둔다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 가시꽃을 피해 길을 지난다.
- **최소 의도 예시 — 사용자 비노출:** “가시가 있는 꽃만 뛰어넘어.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 조건 범위를 좁히기. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 닫힌 꽃은 걸어 지나고 가시꽃 앞에서만 뛴다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 5-5. 중력 문턱

- **요소 3개:** 뒤집힘 아치 — 경계, 가시 — 위험, 출구 — 목표.
- **공간:** 왼쪽 바닥 길이 굵은 아치를 지나 오른쪽 천장 길로 이어진다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 문턱 뒤의 가시를 넘고 출구에 닿는다.
- **최소 의도 예시 — 사용자 비노출:** “문턱을 지나 가시를 뛰어넘어.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 같은 행동을 새 방향에 적용. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 아치에서만 몸의 방향이 바뀌고 바뀐 지면에서 뛴다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 5-6. 정원의 출구

- **요소 3개:** 낮은 덩굴 — 상부 위험, 가시 — 바닥 위험, 출구 — 목표.
- **공간:** 완만한 굽은 길에 덩굴과 가시가 겹치지 않고 떨어져 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 두 위험을 지나 출구에 닿는다.
- **최소 의도 예시 — 사용자 비노출:** “덩굴 아래는 걷고 가시는 뛰어넘어.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 익숙한 예외와 일반 행동의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 각 위험을 만날 때 용사의 몸동작이 달라진다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

중력은 아치 경계에서만 바뀐다. 카메라나 화면을 회전하지 않으며, 몸·덩굴·흙가루의 방향으로 보여 준다. 예외는 눈앞의 위험에 붙인 짧은 조건이며 지침 우선순위 표나 범용 규칙 편집 시험으로 확대하지 않는다.

## 이야기와 장의 음악

동행 자리만 작은 빛 모양으로 빈 벽화. “화분은 거꾸로 자라도, 곁에 있던 자리는 그대로다.”

이야기 소품은 장면 완료 뒤 짧은 선택 장면으로 보여 준다. 퍼즐 화면의 상호작용 대상이나 숨은 조건으로 추가하지 않는다. 모루와 편지, 등지기의 기존 서사 연결과 용사의 외형은 유지한다.

- **대표 분위기:** 고개를 들어 올려다보는 온실의 부드러운 낯섦. 방향이 달라도 무섭거나 혼란스럽기보다 천천히 익숙해지는 정원이다.
- **음색:** 뜯는 하프, 가벼운 현의 하모닉스, 숨이 짧은 목관. 같은 선율의 오르내림을 달리해 뒤집힌 느낌을 내되, 역재생 효과나 급격한 좌우 이동으로 불안·멀미를 만들지 않는다.

여섯 장면은 같은 장의 모티프를 이어 쓴다. 첫 장면은 성기게, 마지막에는 음색을 조금 모으되 실제 장치 소리와 구분한다. 실패 때 곡을 처음부터 재생하거나 음악으로 정답을 알려 주지 않는다. 음소거에서도 움직임과 인과를 모두 읽을 수 있다. 음악 제작 제안이며 새 음원 구현을 뜻하지 않는다.

## 이 장의 검증 경계

- 960×500 안에서 필수 요소와 출발·결과가 동시에 보이며 화면 밖 대상이나 가로 스크롤이 없다.
- 목적 한 문장 이외의 설명 없이도 무엇이 막혔고 행동 뒤 무엇이 바뀌었는지 몸·공간·움직임으로 읽힌다.
- 최초 장면은 한두 의도로 끝나고, 후반 재회도 긴 문장이나 물리 계산을 요구하지 않는다.
- 장면별 이름·요소 수·인과가 실제 렌더링과 일치한다. 장식으로 보이는 숨은 정답 물체가 없다.
- 실패 뒤 현재 장면만 다시 하며 문장 수정 비용과 앞 장면 재플레이가 없다.
- 플레이 시간과 재미는 사람 플레이로 검증하기 전까지 수치 성과로 주장하지 않는다.
