# 4장 — 바람 대장간

> 현재 설계 v3 · shared-v1 · 6장면 · 기준 화면 960×500. 코드와 검증 상태는 별도로 확인한다. 이전 복합 설계는 [역사 기록](../history/stage-design-v1/README.md)이며 구현 요구사항이 아니다.

## 장의 중심 — 바꾼 상태가 남는다

원인과 결과를 같은 화면에서 본 뒤 하나의 결과만 다음 장면으로 잇는다.

[공통 플레이 계약](00-play-contract.md)을 따른다. 메모는 장 입구에서 시작한 한 생 동안 장면을 건너 누적·실행된다. 실패하면 장 입구로 돌아가 한 줄을 추가하며, 이전 장의 설명서나 물체 속성표를 읽어야 풀리는 장면은 만들지 않는다.

## 사용자에게 보이는 문구

입장할 때 아래 목적 한 문장을 한 번 보여 주고 구분에 필요한 사물 이름만 남긴다. 확인 팝업은 없다. 명령 예시, 요소 역할, 세부 완료 판정과 해법은 개발자용 정보이며 UI에 표시하지 않는다. 해야 할 일은 알리되 해결 순서는 말하지 않는다.

| 장면 | 입장 목적 한 문장 |
| --- | --- |
| 4-1 잠든 풍차 | 잠든 풍차를 깨워야 해요. |
| 4-2 바람 승강판 | 위층에 올라가야 해요. |
| 4-3 뜨거운 길 | 철판 너머로 가야 해요. |
| 4-4 회전날개 통로 | 날개 너머로 가야 해요. |
| 4-5 붙잡아 둔 바람 | 다음 방으로 바람이 흐르게 해야 해요. |
| 4-6 이어진 바람 | 편지와 함께 대장간을 나가야 해요. |

## 제작·검증용 장면 명세

아래 수와 역할은 내부 설계 검증용이다. 도착점·위험·관찰 대상·조작 물건을 모두 세며, 일반 바닥과 배경 장식만 제외한다. 연결된 물건을 묶어 수를 숨기지 않는다. 용사와 등지기는 수에서 제외하지만 등지기의 별도 역할은 인지 부담으로 검토한다.

### 4-1. 잠든 풍차

- **요소 2개:** 바람판 — 조작, 풍차 — 목표.
- **공간:** 왼쪽 바람판에서 오른쪽 위 풍차까지 바람의 경로가 보인다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 풍차를 돌린다.
- **최소 의도 예시 — 사용자 비노출:** “바람판을 풍차 쪽으로 돌려.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 방향이 만드는 결과. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 바람 입자의 방향이 바뀌고 풍차가 돈다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 4-2. 바람 승강판

- **요소 3개:** 바람판 — 조작, 승강대 — 운반, 위층 — 목표.
- **공간:** 중앙 승강대 아래로 바람길이 이어지고 위층은 오른쪽 위다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 위층에 도착한다.
- **최소 의도 예시 — 사용자 비노출:** “바람을 승강대로 보내고 올라타.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 설정의 유지. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 손을 놓아도 바람이 흐르고 승강대가 올라간다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 4-3. 뜨거운 길

- **요소 3개:** 송풍기 — 조작, 뜨거운 철판 — 위험, 출구 — 목표.
- **공간:** 중앙 철판이 길을 이루고 송풍기는 바로 옆에서 철판을 향한다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 식은 철판을 건넌다.
- **최소 의도 예시 — 사용자 비노출:** “철판을 식히고 건너.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 남는 상태 변화. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 열기와 아지랑이가 멎고 식은 표면이 남는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 4-4. 회전날개 통로

- **요소 3개:** 바람판 — 조작, 회전날개 — 위험, 출구 — 목표.
- **공간:** 중앙 회전날개가 길 아래까지 닿고 바람판은 앞쪽에 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 멈춘 날개 아래를 지난다.
- **최소 의도 예시 — 사용자 비노출:** “바람을 옆으로 돌리고 지나가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 힘을 끊는 변화. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 바람이 옆으로 빠지고 날개가 천천히 멈춘다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 4-5. 붙잡아 둔 바람

- **요소 2개:** 풍로문 — 조작, 걸쇠 — 고정.
- **공간:** 닫힌 관 입구의 문 옆에 열린 문을 받는 걸쇠가 붙어 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 풍로문을 열린 채 고정한다.
- **최소 의도 예시 — 사용자 비노출:** “풍로문을 열어 걸어 둬.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 일시 동작을 고정하기. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 문이 걸쇠에 걸려 손을 놓아도 열려 있고 바람이 오른쪽 관으로 흐른다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

### 4-6. 이어진 바람

- **요소 3개:** 고정 바람관 — 앞 장면의 결과, 승강대 — 운반, 출구 — 목표.
- **공간:** 앞 장면의 관 끝에서 중앙 승강대로 바람이 흐르고 출구는 오른쪽 위다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 승강대를 타고 출구에 닿는다.
- **최소 의도 예시 — 사용자 비노출:** “승강대를 타고 올라가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 앞에서 남긴 결과 이용. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 짧은 관 연결 전환 뒤 바람이 이미 흐르는 승강대에 탄다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 장 입구의 다음 생에서 한 줄을 추가한다. 해석이 불명확하면 실행 전에 확인하고 안전하게 멈춘다.

4-5→4-6 전환은 관선을 따라 이어지는 짧은 시각 전환으로 풍로의 연속을 보여 준다. 4-6 시작 스냅샷에는 열린 풍로가 포함되어, 실패해도 4-5를 다시 풀지 않는다. 앞 장면의 문은 현재 조작 목록으로 재노출하지 않는다.

## 이야기와 장의 음악

풍로 옆에 겹친 작은 두 손자국. “이건 혼자 들면 자꾸 기울었는데.”

이야기 소품은 장면 완료 뒤 짧은 선택 장면으로 보여 준다. 퍼즐 화면의 상호작용 대상이나 숨은 조건으로 추가하지 않는다. 모루와 편지, 등지기의 기존 서사 연결과 용사의 외형은 유지한다.

- **대표 분위기:** 커다란 기계 안에서 바람길을 하나씩 깨우는 든든함. 화덕은 위협적인 공장보다 손으로 다루는 오래된 작업장에 가깝다.
- **음색:** 낮고 부드러운 리드 오르간, 숨결이 있는 플루트, 둥글게 울리는 금속 타악. 망치 타격음을 음악 리듬으로 겹쳐 쓰지 않고, 열기와 냉각은 실제 장치 소리가 담당한다.

여섯 장면은 같은 장의 모티프를 이어 쓴다. 첫 장면은 성기게, 마지막에는 음색을 조금 모으되 실제 장치 소리와 구분한다. 실패 때 곡을 처음부터 재생하거나 음악으로 정답을 알려 주지 않는다. 음소거에서도 움직임과 인과를 모두 읽을 수 있다. 음악 제작 제안이며 새 음원 구현을 뜻하지 않는다.

## 이 장의 검증 경계

- 960×500 안에서 필수 요소와 출발·결과가 동시에 보이며 화면 밖 대상이나 가로 스크롤이 없다.
- 목적 한 문장 이외의 설명 없이도 무엇이 막혔고 행동 뒤 무엇이 바뀌었는지 몸·공간·움직임으로 읽힌다.
- 최초 장면은 한두 의도로 끝나고, 후반 재회도 긴 문장이나 물리 계산을 요구하지 않는다.
- 장면별 이름·요소 수·인과가 실제 렌더링과 일치한다. 장식으로 보이는 숨은 정답 물체가 없다.
- 실패는 현재 생의 기록을 남기고 장 입구로 돌아가며, 누적 메모와 우선순위와 지우개는 유지된다.
- 플레이 시간과 재미는 사람 플레이로 검증하기 전까지 수치 성과로 주장하지 않는다.
