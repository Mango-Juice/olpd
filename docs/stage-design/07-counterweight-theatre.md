# 7장 — 평형 인형극장

> 현재 설계 v2 · 6장면 · 기준 화면 960×500. 코드와 검증 상태는 별도로 확인한다. 이전 복합 설계는 [역사 기록](../history/stage-design-v1/README.md)이며 구현 요구사항이 아니다.

## 장의 중심 — 등지기와 한 역할씩

한 사람의 이동과 다른 사람의 유지를 짧은 장면으로 나눈다.

[공통 플레이 계약](00-play-contract.md)을 따른다. 현재 장면에서 무료로 문장을 고치고 다시 해 본다. 이미 마친 장면을 다시 통과할 필요는 없다. 이전 장의 설명서나 물체 속성표를 읽어야 풀리는 장면은 만들지 않는다.

## 사용자에게 보이는 문구

입장할 때 아래 목적 한 문장을 한 번 보여 주고 구분에 필요한 사물 이름만 남긴다. 확인 팝업은 없다. 명령 예시, 요소 역할, 세부 완료 판정과 해법은 개발자용 정보이며 UI에 표시하지 않는다. 해야 할 일은 알리되 해결 순서는 말하지 않는다.

| 장면 | 입장 목적 한 문장 |
| --- | --- |
| 7-1 첫 동행 | 등지기와 만나야 해요. |
| 7-2 잡고 있기 | 등지기가 무대막을 들어 줘야 해요. |
| 7-3 내가 지나간 뒤 | 용사도 건너가고, 등지기도 자유로워져야 해요. |
| 7-4 역할 바꾸기 | 이번엔 등지기를 막 너머로 보내야 해요. |
| 7-5 함께 나르기 | 함께 건너편으로 가야 해요. |
| 7-6 둘이 도착하기 | 등지기와 함께 극장을 나가야 해요. |

## 제작·검증용 장면 명세

아래 수와 역할은 내부 설계 검증용이다. 도착점·위험·관찰 대상·조작 물건을 모두 세며, 일반 바닥과 배경 장식만 제외한다. 연결된 물건을 묶어 수를 숨기지 않는다. 용사와 등지기는 수에서 제외하지만 등지기의 별도 역할은 인지 부담으로 검토한다.

### 7-1. 첫 동행

- **요소 2개:** 합류 자리 — 등지기 목표, 무대길 — 경로.
- **공간:** 용사는 오른쪽, 등지기는 짧은 레일의 왼쪽에 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 등지기가 곁에 온다.
- **최소 의도 예시 — 사용자 비노출:** “등지기야 이쪽으로 와.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 행동 주체 지정. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 용사는 기다리고 등지기만 다가온다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 7-2. 잡고 있기

- **요소 2개:** 막 손잡이 — 유지, 무대막 — 결과.
- **공간:** 손잡이는 왼쪽, 연결된 줄은 오른쪽의 높은 막으로 이어진다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 등지기가 막을 올려 잡는다.
- **최소 의도 예시 — 사용자 비노출:** “등지기는 손잡이를 잡고 있어.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 유지 역할. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 손이 손잡이를 쥐고 줄이 팽팽해지며 막이 올라간다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 7-3. 내가 지나간 뒤

- **요소 3개:** 막 손잡이 — 유지, 무대막 — 장벽, 도착 자리 — 용사 목표.
- **공간:** 등지기가 이미 막을 잡은 상태에서 용사가 그 아래를 지난다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 용사 통과 뒤 등지기가 놓는다.
- **최소 의도 예시 — 사용자 비노출:** “내가 지나가면 등지기는 놓아.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 임무의 종료 사건. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 용사가 반대편에 닿은 다음 손이 풀린다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 7-4. 역할 바꾸기

- **요소 3개:** 낮은 손잡이 — 유지, 무대막 — 장벽, 도착 자리 — 등지기 목표.
- **공간:** 용사가 손잡이 옆에 있고 등지기는 막 앞에 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 용사가 막을 잡는 동안 등지기가 지난다.
- **최소 의도 예시 — 사용자 비노출:** “나는 막을 잡고 등지기는 지나가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 역할 배정 바꾸기. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 이번에는 용사가 멈추고 등지기가 막 아래로 걷는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 7-5. 함께 나르기

- **요소 3개:** 긴 의자 — 공동 물건, 틈 — 위험, 건너편 — 공동 목표.
- **공간:** 긴 의자를 잡을 두 끝과 중앙 틈의 양쪽 턱이 한눈에 보인다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 함께 놓은 의자로 틈을 건넌다.
- **최소 의도 예시 — 사용자 비노출:** “함께 의자를 놓고 건너.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 하나의 물건을 함께 다루기. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 두 손이 각 끝을 잡아 의자를 걸친 뒤 차례로 건넌다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 7-6. 둘이 도착하기

- **요소 3개:** 무대막 — 장벽, 고정 걸쇠 — 조작, 출구 — 공동 목표.
- **공간:** 등지기는 막을 들고 있고 용사는 가까운 걸쇠 옆에 있다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 막을 고정한 뒤 둘 다 출구에 닿는다.
- **최소 의도 예시 — 사용자 비노출:** “막을 걸쇠에 걸고 함께 나가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 유지 임무를 장치에 넘기기. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 막이 걸쇠에 걸린 뒤 등지기도 손을 놓고 따라온다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

등지기는 같은 장면에 보이는 작은 목제 자동인형이다. 별도 채팅·능력표·자율 문제 해결은 없다. 이동·잡기·놓기·함께 들기의 결과를 몸으로 보여 준다. 7-3은 이미 막을 잡은 상태, 7-6도 이미 유지 중인 상태를 시작 스냅샷으로 갖는다. 이전 장면 실패나 기록에 의존하지 않는다.

## 이야기와 장의 음악

두 인형이 손을 맞잡은 그림자극. “한 손이 막을 들면, 다른 손은 길을 건넜다.”

이야기 소품은 장면 완료 뒤 짧은 선택 장면으로 보여 준다. 퍼즐 화면의 상호작용 대상이나 숨은 조건으로 추가하지 않는다. 모루와 편지, 등지기의 기존 서사 연결과 용사의 외형은 유지한다.

- **대표 분위기:** 두 손이 서로의 차례를 기다리는 작은 인형극. 서툰 동행의 다정함과 막이 오르는 기대가 중심이며 곡예처럼 조급하지 않다.
- **음색:** 목금과 낮은 바순이 짧은 선율을 주고받고 부드러운 현이 잇는다. 두 선율은 용사와 등지기의 관계를 느끼게 하지만, 임무 상태나 해제 시점을 음악만으로 전달하지 않는다.

여섯 장면은 같은 장의 모티프를 이어 쓴다. 첫 장면은 성기게, 마지막에는 음색을 조금 모으되 실제 장치 소리와 구분한다. 실패 때 곡을 처음부터 재생하거나 음악으로 정답을 알려 주지 않는다. 음소거에서도 움직임과 인과를 모두 읽을 수 있다. 음악 제작 제안이며 새 음원 구현을 뜻하지 않는다.

## 이 장의 검증 경계

- 960×500 안에서 필수 요소와 출발·결과가 동시에 보이며 화면 밖 대상이나 가로 스크롤이 없다.
- 목적 한 문장 이외의 설명 없이도 무엇이 막혔고 행동 뒤 무엇이 바뀌었는지 몸·공간·움직임으로 읽힌다.
- 최초 장면은 한두 의도로 끝나고, 후반 재회도 긴 문장이나 물리 계산을 요구하지 않는다.
- 장면별 이름·요소 수·인과가 실제 렌더링과 일치한다. 장식으로 보이는 숨은 정답 물체가 없다.
- 실패 뒤 현재 장면만 다시 하며 문장 수정 비용과 앞 장면 재플레이가 없다.
- 플레이 시간과 재미는 사람 플레이로 검증하기 전까지 수치 성과로 주장하지 않는다.
