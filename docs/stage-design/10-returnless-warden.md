# 10장 — 돌아오지 못한 문지기

> 현재 설계 v2 · 6장면 · 기준 화면 960×500. 코드와 검증 상태는 별도로 확인한다. 이전 복합 설계는 [역사 기록](../history/stage-design-v1/README.md)이며 구현 요구사항이 아니다.

## 장의 중심 — 함께 마지막 문으로

위협이 길로 바뀌는 세 번의 변화 뒤 등지기와 함께 편지의 문에 닿는다.

[공통 플레이 계약](00-play-contract.md)을 따른다. 현재 장면에서 무료로 문장을 고치고 다시 해 본다. 이미 마친 장면을 다시 통과할 필요는 없다. 이전 장의 설명서나 물체 속성표를 읽어야 풀리는 장면은 만들지 않는다.

## 사용자에게 보이는 문구

입장할 때 아래 목적 한 문장을 한 번 보여 주고 구분에 필요한 사물 이름만 남긴다. 확인 팝업은 없다. 명령 예시, 요소 역할, 세부 완료 판정과 해법은 개발자용 정보이며 UI에 표시하지 않는다. 해야 할 일은 알리되 해결 순서는 말하지 않는다.

| 장면 | 입장 목적 한 문장 |
| --- | --- |
| 10-1 팔이 비킨 자리 | 팔 너머 안전한 자리로 가야 해요. |
| 10-2 첫 갑옷 | 첫 갑옷 너머로 가야 해요. |
| 10-3 뜨거운 틈 | 갑옷 안쪽으로 들어가야 해요. |
| 10-4 접힌 날개 | 문지기의 가슴 앞에 닿아야 해요. |
| 10-5 마지막 매듭 | 마지막 걸쇠를 풀어 문지기를 자유롭게 해 줘요. |
| 10-6 돌아가는 문 | 등지기와 함께 마지막 문을 지나야 해요. |

## 제작·검증용 장면 명세

아래 수와 역할은 내부 설계 검증용이다. 도착점·위험·관찰 대상·조작 물건을 모두 세며, 일반 바닥과 배경 장식만 제외한다. 연결된 물건을 묶어 수를 숨기지 않는다. 용사와 등지기는 수에서 제외하지만 등지기의 별도 역할은 인지 부담으로 검토한다.

### 10-1. 팔이 비킨 자리

- **요소 2개:** 문지기 팔 — 주기 위험, 안전 자리 — 목표.
- **공간:** 중앙 팔이 접히면 오른쪽 안전 자리까지 짧은 길이 열린다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 팔이 비킨 자리를 지난다.
- **최소 의도 예시 — 사용자 비노출:** “팔이 접히면 지나가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 사건 대기의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 팔이 몸 안으로 들어간 뒤 빈 길로 이동한다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 10-2. 첫 갑옷

- **요소 2개:** 갑옷 걸쇠 — 조작, 갑옷판 — 길과 목표.
- **공간:** 걸쇠는 손 닿는 옆면에 있고 갑옷판은 앞길을 막는다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 걸쇠를 풀고 내려온 판을 지난다.
- **최소 의도 예시 — 사용자 비노출:** “걸쇠를 풀고 갑옷판을 건너.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 첫 봉인 해제. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 판이 내려와 다리가 되고 갑옷의 첫 빛이 잦아든다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 10-3. 뜨거운 틈

- **요소 3개:** 냉각 바람판 — 조작, 뜨거운 갑옷길 — 위험, 안쪽 — 목표.
- **공간:** 중앙 갑옷길에서 열기가 오르고 앞쪽 바람판이 그 길을 향한다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 갑옷길을 식히고 안쪽에 닿는다.
- **최소 의도 예시 — 사용자 비노출:** “갑옷길을 식히고 들어가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 지속 상태의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 열선이 사라지고 식은 길이 남는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 10-4. 접힌 날개

- **요소 3개:** 바람판 — 조작, 날개 — 장벽과 길, 가슴 앞 — 목표.
- **공간:** 오른쪽 날개가 길을 막고 바람의 방향이 날개와 연결된다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 날개를 접어 가슴 앞에 닿는다.
- **최소 의도 예시 — 사용자 비노출:** “바람을 돌려 날개를 접고 건너.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 두 번째 봉인 해제. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 접힌 날개가 계단으로 고정되고 두 번째 빛이 잦아든다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 10-5. 마지막 매듭

- **요소 2개:** 유지 고리 — 등지기 조작, 마지막 걸쇠 — 용사 목표.
- **공간:** 고리는 왼쪽 아래, 걸쇠는 중앙의 손 닿는 위치다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 등지기가 고리를 잡는 동안 걸쇠를 푼다.
- **최소 의도 예시 — 사용자 비노출:** “등지기는 고리를 잡고 나는 걸쇠를 풀어.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 역할 분담의 재회. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 세 번째 봉인이 풀리면 연결된 줄이 느슨해지고 등지기도 놓는다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

### 10-6. 돌아가는 문

- **요소 2개:** 마지막 문 — 조작, 문 너머 자리 — 공동 목표.
- **공간:** 왼쪽의 둘에서 중앙 문을 지나 오른쪽 빛으로 곧게 이어진다. 카메라 이동이나 가로 스크롤 없이 출발과 결과가 함께 보인다.
- **단일 목표:** 문을 열고 둘이 함께 지난다.
- **최소 의도 예시 — 사용자 비노출:** “문을 열고 함께 가.” 같은 의도를 다른 문장으로 써도 인정한다.
- **이번 장면의 한 초점:** 동행의 완성. 익힌 동작은 새 설명 없이 재사용한다.
- **눈으로 보이는 인과:** 둘이 문 너머에 닿은 다음 편지의 기존 결말을 연다.
- **회복:** 실패한 접촉이나 멈춘 이유를 짧게 보여 주고 현재 장면의 시작 배치에서 무료로 다시 한다. 해석이 불명확하면 실행 전에 무료로 확인한다.

세 봉인은 10-2·10-4·10-5의 세계 변화다. 봉인당 두 비트나 전용 자원 배분을 강제하지 않는다. 모든 장면 완료를 따로 저장하고 이미 푼 봉인은 다시 닫히지 않는다. 갑옷의 나머지 부분은 저대비 배경이며 현재 조작부만 또렷하게 보인다. 등지기는 마지막 협력 전까지 안전한 뒤편에서 동행한다. 문지기의 움직임은 결정적이고 현실 입력 속도나 과거 사망 수에 반응하지 않는다. 10-5는 걸쇠가 풀리면 줄이 느슨해지는 직접 연결로 임무 종료를 보여 준다.

## 이야기와 장의 음악

편지의 받는 사람 칸에는 용사의 이름이 있다. “여기까지는 내가 길을 적었어. 다음 길은 네가 골라 줘. 이제는 같이 가자.”

이야기 소품은 장면 완료 뒤 짧은 선택 장면으로 보여 준다. 퍼즐 화면의 상호작용 대상이나 숨은 조건으로 추가하지 않는다. 모루와 편지, 등지기의 기존 서사 연결과 용사의 외형은 유지한다.

- **대표 분위기:** 거대한 문 앞의 무게감과, 함께 나갈 길을 찾는 담담한 결심. 공포·분노보다 오래 남은 힘을 풀어 주는 마지막 여정에 가깝다.
- **음색:** 낮은 현, 부드러운 금관의 긴 호흡, 드문 목재 타악에 1장의 짧은 선율을 희미하게 섞는다. 빠른 전투 드럼이나 팔 동작과 일치하는 강박은 쓰지 않는다.

여섯 장면은 같은 장의 모티프를 이어 쓴다. 첫 장면은 성기게, 마지막에는 음색을 조금 모으되 실제 장치 소리와 구분한다. 실패 때 곡을 처음부터 재생하거나 음악으로 정답을 알려 주지 않는다. 음소거에서도 움직임과 인과를 모두 읽을 수 있다. 음악 제작 제안이며 새 음원 구현을 뜻하지 않는다.

## 이 장의 검증 경계

- 960×500 안에서 필수 요소와 출발·결과가 동시에 보이며 화면 밖 대상이나 가로 스크롤이 없다.
- 목적 한 문장 이외의 설명 없이도 무엇이 막혔고 행동 뒤 무엇이 바뀌었는지 몸·공간·움직임으로 읽힌다.
- 최초 장면은 한두 의도로 끝나고, 후반 재회도 긴 문장이나 물리 계산을 요구하지 않는다.
- 장면별 이름·요소 수·인과가 실제 렌더링과 일치한다. 장식으로 보이는 숨은 정답 물체가 없다.
- 실패 뒤 현재 장면만 다시 하며 문장 수정 비용과 앞 장면 재플레이가 없다.
- 플레이 시간과 재미는 사람 플레이로 검증하기 전까지 수치 성과로 주장하지 않는다.
