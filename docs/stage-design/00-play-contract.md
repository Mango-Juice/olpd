# 공통 설계 규칙 — 문장을 쓰는 일이 곧 풀이가 되게

> **2~10장에 적용할 확장 제안이다. 기존 1장은 현재의 8개 방과 네 행동·메모 규칙을 그대로 유지한다.** 현재 구현과 다른 항목은 아래에 명시했다. 장별 예문은 해법 검토용이며 고정 문법이나 유일 정답이 아니다.

## 기존 1장과의 경계

1장에 물건 조작·여러 행동을 엮은 한 줄·발견 책갈피·새 위험 앞 안전 정지를 넣지 않는다. 2장 입구의 안전한 연습에서 물건을 지목하고 옮기는 첫 상호작용을 소개하고 확장 규칙을 안내한다. 1장에서 가져온 단일 행동 지침도 기존 의미를 보존한 채 활성 메모에 옮긴다. 5장은 조건과 우선순위의 첫 도입이 아니라, 1장에서 배운 원리를 물체 상태와 지역 범위로 심화하는 장이다.

## 1. 자유의 범위: 표현은 열고, 세계의 법칙은 고정한다

자유로운 입력을 무제한 마법으로 처리하지 않는다. 화면 속 물체에는 일관된 성질과 상호작용이 있다. 같은 받침은 다리를 지지하고, 문을 받치고, 물건을 높일 수 있다. 쓰임새마다 따로 숨은 정답 표식을 붙이지 않는다.

물건을 살펴보면 재질, 이동 가능 여부, 잡을 곳, 닿는 범위, 현재 상태를 알 수 있다. 수치가 중요하면 눈금·칸·추와 텍스트로 확인한다. 반대로 풀기에 필요 없는 무게 숫자를 외우게 하지 않는다. 도구의 관계를 발견하는 것이 퍼즐이고, 해당 관계가 지원되는지 추측하는 것은 퍼즐이 아니다.

- “상자를 밀어 발판 아래에 둬”, “발판 밑까지 나무 상자를 옮겨”는 같은 의도로 인정한다.
- “돌아가”, “통을 세워”, “멈춰”처럼 대상이나 상태가 여러 뜻이면 원문의 해당 부분을 짚어 다시 쓰게 한다. 정답 동사 목록을 내밀지 않는다.
- “문을 열어”는 눈앞의 손잡이 하나를 여는 일이라면 충분하다. 여러 기계를 해결해야 한다면 “무엇을 이용해 열지 아직 모르겠어”라고 설명한다. AI가 플레이어 대신 퍼즐 전체를 풀지 않는다.
- “안전하게”, “잘”, “알아서”는 새로운 능력이나 미래 지식을 만들지 않는다. “안전하게 건너”만으로 최적 경로를 자동 탐색하지 않는다.
- 세계에 없는 비행·순간이동·무한 복제는 이해 가능한 요청이라도 실행 가능한 능력이 아님을 알려 준다. 생명을 소모해 알아내게 하지 않는다.
- 물리적으로 할 수 있는 행동을 잘못된 곳에서 하면 실제로 실패할 수 있다. 무거운 돌을 얇은 판자에 올리는 일은 해석 오류가 아니며, 판자의 휨과 파손 원인을 보여 준다.

상호작용 하나를 추가할 때 연관 장면도 함께 확인한다. “이 방의 상자만 문을 못 받친다”처럼 제작자의 의도 밖 해법을 막기 위한 예외는 만들지 않는다. 합리적인 우회 풀이가 성립하면 통과시킨다. 세계의 재질·크기·연결 구조로 불가능한 것은 그 이유가 보이게 한다.

## 2. 문장 UI와 해석 결과

입력창은 자유 문장 한 줄이다. 장식적으로 “다음에는…”을 붙일 수 있지만 조사나 빈칸 종류를 강제하지 않는다. 초반에는 짧은 문장으로 충분하고, 후반에는 “A면 B하고, C가 될 때까지 유지한 뒤 D해”도 가능하다. 행동 수를 장별로 해금하지 않는다.

목표는 200자 안팎에서도 편하게 작성하는 UI이며 80자 제한은 재검토한다. 글자 수를 퍼즐 자원으로 삼지 않고, 문장이 과도하게 길어지는 방은 중간 목표를 나눈다. 구현의 안전 제한이 필요해도 조용히 잘라 실행하지 않는다.

- 입력 전에는 현재 장면의 **사실**과 달성할 **목표**를 보여 준다. 목적에 필요한 핵심 시야를 가리지 않는다.
- 첫 입력과 새 문장 관계를 처음 쓸 때 “통을 먼저 놓고 → 올라탄 뒤 → 물가에서 내릴게”처럼 실행 의도를 짧게 되읽는다. 이후 같은 관계는 빠르게 진행한다.
- 미리보기는 플레이어의 의도를 확인한다. 아직 관찰하지 않은 경로나 최적 해법, 미래 실패 여부를 알려 주는 자동 풀이기가 아니다.
- “잡아 둬”와 “한 번 당겨”처럼 결과가 다른 해석은 확정 전에 확인한다. 표현을 명확히 하는 수정에는 작성 기회·지우개·종 횟수를 쓰지 않는다.
- 알려진 물체를 가리키는 비유·별칭·동의어는 연결할 수 있다. 물체 자체나 능력을 새로 창작하지 않는다.
- 모델 응답 지연·통신 오류·해석 실패는 게임의 사망이 아니다. 같은 확정 문장과 같은 상태는 같은 결과를 내야 한다.

## 3. 실행의 의미

### 대상과 범위

지침은 현재 보이거나 현재 시도에서 확인한 대상을 가리킨다. 목표가 다른 방에 있을 때는 이 방의 물체에 멋대로 대입하지 않는다. “상자”가 둘이면 위치·재질·표식을 확인한다. 한 대상을 정한 뒤 이동했다고 중간에 다른 상자로 바뀌지 않는다.

지침의 적용 범위는 물체 또는 상황 중심이다. 방 번호 암기가 정답이 되는 지시를 필수로 요구하지 않는다. 장 번호나 이름으로 한정하는 표현도 원하면 허용한다.

### 순서와 지속

“밀고 올라가”는 앞 행동의 완료 뒤 다음 행동을 시작한다. 한 번 시작한 절차는 다음 행동 경계에서 상태를 확인하며 이어 간다. 첫 조건이 사라졌다는 이유만으로 성공 중인 절차를 처음부터 다시 시작하지 않는다. 실행이 끝난 지침은 같은 상황에서 무한 반복하지 않고 새로운 사건·재진입을 기다린다.

“누르고 있어”는 해당 주체가 자리를 유지하는 행동이다. 같은 주체에게 이동을 지시하면 유지가 끝난다. 이를 모순된 명령이라며 임의로 둘 다 성공시키지 않는다. “인형이 누르는 동안 나는 건너”는 두 주체의 동시 행동이다. 인형의 능력·사거리도 먼저 보여 준다.

“문이 완전히 열리면”은 사건 기준이다. 실시간 키 입력이나 0.2초 단위 타이핑을 요구하지 않는다. 게임 내 이동 속도와 장치 주기가 안전 창을 결정한다. 3배속·일시정지·프레임 저하는 결과를 바꾸지 않는다.

### 여러 줄의 우선순위

현재 게임의 **화면 위쪽에서 먼저 적용되는 줄을 선택**하는 원리를 유지한다. 출발 전 순서 변경은 무료다. ‘새 줄이 무조건 우선’이라는 옛 규칙은 쓰지 않는다.

실행 중인 절차는 자기 차례를 이어 간다. 더 높은 줄이 명시적으로 경계하는 상황이 발생하면 다음 안전한 행동 경계에서 중단하고 그 줄을 따른다. 이미 공중에 뜬 몸을 순간이동시키지는 않는다. 중단된 절차를 자동으로 처음부터 반복하지 않고, 계속할 수 있는지와 중단 지점을 기록한다. 이런 중단이 필요한 장면에는 중단 가능한 발판이나 정지 공간을 마련한다.

일반 규칙과 예외 규칙이 겹치면 출발 전에 겹치는 관찰 조건을 보여 준다. 현재의 ‘적용 상황 전체가 같고 행동만 다르면 저장 거절’은 확장된 상태·순서·주체를 구분하도록 재설계해야 한다. 이 캠페인에서는 겹침 자체를 금지하지 않고, 가려지는 줄을 경고하며 플레이어가 우선순위를 정한다.

### 기억과 관찰

메모장의 **지침**은 되감아도 남고, 세계의 **관찰 사실**은 시도에 속한다. “무늬를 확인한 뒤 기억해”라는 지침은 유지되지만 이전 시도에서 본 ‘이번 화물은 오른쪽 선로’라는 사실은 현재 값으로 사용할 수 없다. 화면의 사실 기록에도 이전 시도 표식을 붙인다.

‘알 수 없음’과 ‘거짓’을 구별한다. 확인하지 못한 신호를 반대 신호로 취급하지 않는다. 관찰이 필요하면 그 자리에 가거나 시야를 확보하는 행위를 문장에 담는다. “기억해”만으로 보이지 않는 정답을 얻지 않는다.

## 4. 시도, 죽음, 메모장 — 오래 하는 만큼 다시 걷게 하지는 않는다

| 항목 | 캠페인 제안 |
| --- | --- |
| 장 시작 | 안전한 관찰 공간과 무료 첫 한 줄. 해당 장에서 처음 보는 기본 상호작용은 별도의 작은 연습 공간에서 비용 없이 시험 가능 |
| 연습 공간 | 실제 첫 배치의 정답을 대신 풀어 주지 않는 축소 장치. 연습 메모·사망은 본편 기록과 분리하고 종료 시 초기화 |
| 새 구간 첫 도달 | 각 장 문서의 02-1 같은 설계 구간 시작에는 안전한 관찰 책갈피가 있다. 처음 도달했을 때만 새 한 줄 기회를 한 번 주며 장 첫 줄과 중복 지급하지 않는다. 미사용 기회는 누적되지 않음 |
| 발견 기회 보존 | 책갈피 사용 이력은 저장·되감기 밖에 남아 재방문으로 새 줄을 얻을 수 없음. 모호한 해석·통신 실패로는 사용 처리하지 않음 |
| 일반 시도 | 확정된 지침으로 자동 진행. 실패 또는 자진 되감기 한 번에 새 한 줄 기회 한 번, 미사용 기회 누적 없음 |
| 작성 기회 사용 | 새 한 줄 추가 또는 기존 한 줄 수정 중 하나. 수정은 기존 줄 삭제 비용도 적용. 해석을 고치는 입력 단계의 수정은 무료 |
| 삭제 | 장마다 지우개 2개. 이후 한 줄 삭제에 +3회 종. 여러 줄을 한 번에 공짜로 교체하지 않음 |
| 기존 지침 | 완료 장의 메모 원본은 보관. 새 장 첫 출발 전에 필요한 줄을 활성 메모로 무료 복사 가능. 이후 활성 줄 추가·수정은 일반 기회 규칙 적용 |
| 재배치 | 출발 전과 새 구간의 최초 안전 책갈피에서 우선순위 변경 무료. 이미 시작한 행동이나 대기 도중에는 지침을 바꾸지 않음 |
| 장 체크포인트 | 완료한 장은 다시 풀 필요 없음. 실패하면 현재 장의 시작으로, 물건·장치·현재 관찰 사실 초기화 |
| 재생 | 동일한 지침·시작 상태로 이미 통과한 구간은 빠르게 압축. 앞선 변경이 영향을 주면 다시 계산하고 변화 지점을 보여 줌 |
| 중단·교착 | 실패 원인을 즉시 보여 주고 되감기 가능. 끝없는 대기나 자동 실패 반복 없음. 단순 해석 오류에는 되감기를 요구하지 않음 |
| 보스 | 세 봉인 단위 체크포인트. 봉인 통과 때 다음 구간의 무료 한 줄. 장별 예외를 입장 시 안내 |

장 시작·새 구간 최초 발견의 한 줄과 연습 공간은 새 규칙을 배우기 위한 강제 사망을 줄이는 **현행 규칙의 확장 제안**이다. 제목의 기존 원칙에서 실패에 한 줄을 얻는 부분은 유지하되, 새로운 문제에 처음 가설을 세울 기회도 준다. 각 장 다섯 구간이면 발견 기회는 최대 다섯 번이며 장 첫 줄이 그 안에 포함된다. 보스 여섯 비트도 각각 한 번이고 봉인 전환 무료 한 줄과 중복 지급하지 않는다. 한 구간 안에서 새 물건이 나올 때마다 쓰기 위해 일부러 죽어야 한다면 배치를 바꾸거나 별도 설계 구간으로 나눈다. 구간 시작에 목표와 필요한 물체는 관찰 가능해야 한다. 대표 해법이 현재 활성 메모와 새로운 한 줄로 표현되는지 설계 단계에서 직접 점검한다.

기본 전진도 바꾼다. 관찰된 안전한 열린 길에서는 전진하지만, 지시가 없는 상호작용·갈림길·새 위험 앞에서는 멈추고 이유를 알린다. 멈춤 자체는 사망으로 세지 않는다. 최초 관찰 책갈피라면 그곳의 발견 기회를 사용한다. 이미 그 구간의 기회를 썼고 새 한 줄이 필요하면 자진 되감기를 선택해 종 1회와 작성 기회를 얻는다. 이 과정을 학습량 대신 반복시키지 않는다.

지우개·종은 도전 기록이며 콘텐츠 해금 화폐가 아니다. 적게 죽었다고 다른 스토리를 주거나 많이 죽었다고 보스를 강하게 만들지 않는다. 개발 중 삭제 비용 때문에 안전한 실험이 줄어들면, 실제 실패 기록을 보고 비용 체계를 조정한다.

## 5. 퍼즐 카드의 공정성

모든 핵심 구간은 다음을 충족해야 한다.

1. **목표가 보인다.** 출구 도착, 물건 함께 운반, 장치 해제 중 무엇을 달성해야 하는지 미리 안다.
2. **필수 사실이 보인다.** 무게 제한, 길이, 고정 여부, 흐름 방향, 작동 주기를 필요 전에 확인한다. 화면과 텍스트의 사실이 일치한다.
3. **인과관계가 남는다.** 실패 기록에 적용된 문장, 행동 대상, 바뀐 상태, 막힌 이유를 표시한다.
4. **대안이 실제로 다르다.** 길을 바꾸기, 환경을 바꾸기, 도구를 쓰기 등 적어도 두 계열을 주요 퍼즐에서 허용한다. 안전한 첫 실습은 한 계열이어도 된다.
5. **뜻밖의 합리적인 풀이를 받는다.** 예문 밖 성공을 막는 별도 정답 문자열·해법 ID를 요구하지 않는다.
6. **새 개념 하나를 먼저 분리한다.** 처음부터 새 물건·새 시간 규칙·새 기억 규칙을 동시에 시험하지 않는다.
7. **모든 가설이 한 번은 해 볼 만하다.** 자원은 되감으면 복구된다. 보지 못한 정보 탓에 반복해서 죽이지 않는다.

실패 예시는 “틀린 행동이야” 대신 “네가 발판을 떠나자 문이 닫혔어. 문은 눌리는 동안만 열려”로 쓴다. 예상치 못한 동음이의어 해석을 웃음 소재로 삼아 플레이어를 죽이지 않는다. 웃음은 합의된 행동이 낳은 귀여운 물리 결과에서 나온다.

선택 힌트는 **볼 곳 → 관계 → 예시 문장**의 3단계다. 마지막 단계는 사용자가 명시적으로 더 요청했을 때만 보여 준다. 죽었다는 이유로 자동으로 답을 띄우지 않는다.

## 6. 화면과 서사

현재 [아트 디렉션](../art-direction.md)의 크림색 몸·민트 후드·금빛 달 장식을 기준으로 한다. 스토리 초안의 이전 외형 묘사를 새 에셋 기준으로 쓰지 않는다. 본문 호칭은 용사로 통일한다.

각 장은 배경 팔레트뿐 아니라 실루엣, 재질, 움직임, 물건의 결합 방식이 달라야 한다. 작동 가능 여부와 상태는 형태·위치·무늬·텍스트를 함께 써서 전달한다. 소리를 끄거나 모션을 줄여도 신호를 놓치지 않는다.

장당 선택적 복선은 한 장면/소품을 기본으로 한다. 필수 대사로 조작을 끊지 않는다. 보스의 기계 목표도 이야기와 무관하게 읽힌다. 마지막 편지와 불빛의 귀환은 클리어 이후의 짧고 건너뛸 수 있는 보상이다. 엔딩 전에 수신인이나 길잡이의 정체를 설명하지 않는다.

## 7. 구현·플레이테스트 인수 기준

문서를 구현했다는 판정과 재미있다는 판정을 분리한다.

- 같은 상태에서 동의어·어순 변경·불필요한 수식어가 같은 의도를 유지하는지 확인한다.
- 대상, 순서, 기다림의 끝, 유지 주체를 바꾼 최소 쌍은 서로 다른 결과를 내는지 확인한다.
- AI가 아직 보지 못한 신호를 발명하거나 “알아서 해결”을 완전한 해법으로 확장하지 않는지 확인한다.
- 모든 주요 구간에서 문서의 대안 두 개를 실제 시뮬레이션으로 재현한다. 문장만 다르고 행동이 같다면 미충족이다.
- 상태를 초기화한 뒤 재시도, 다른 이전 경로에서 진입, 저장 후 재개에도 조건이 일치해야 한다.
- 장별 사람 관찰에서는 첫 이해까지 걸린 시간, 자발적 해법의 종류, 해석 수정과 추론 수정의 비율, 의도적 사망이 필요했던 횟수를 기록한다.
- 실패 원인을 설명하지 못하는 사람이 반복되면 설명문을 늘리기 전에 시각 신호·물성·배치를 고친다.
- 재시도 시간의 대부분이 이미 푼 길 재생이라면 압축을 강화하거나 체크포인트 범위를 재조정한다.

외부 게임 사례나 실제 플레이테스트 결과를 근거로 한 수치가 아니다. 출시 전 필요한 검증 항목과 설계 가설을 명확히 둔 것이다.
